# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯머신 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 5 — 라운드 준비 / 명시적 시작 / 납부 게이지 / 금고 잠금 / 재화 연출 / v0.5.8**

현재 구현된 것:

- 핀테크 / 트레이딩 앱 스타일 UI
- 5×3 세로 릴
- v0.1.3에서 확정한 회전 속도 유지
- 가로 3/4/5, 세로, 대각선, V, 역 V, X 패턴 판정
- 겹쳐 성립하는 패턴 전부 합산
- 15칸 전체 동일 심볼 잭팟 + 일반 패턴 동시 합산
- 일반 6회전 / 위험 3회전 선택
- 마감당 플레이 라운드 3개 + 최종 납부용 0라운드
- 마감 확정 버튼 제거 / 목표 납부 완료 시 자동 진행
- 금고 2라운드 / 4라운드 복리 상품
- 방식 선택 후 별도 자금 배분 구간
- 자금 배분 뒤 중앙 `시작` 버튼으로 라운드 확정
- 시작 버튼은 리롤과 분리되며 회전 횟수를 소비하지 않음
- 라운드 시작 뒤에만 실제 `리롤` 버튼 활성
- 이번 준비 구간 납부액을 빨간 게이지로 구분
- 재화 0.6초 ease-out 카운트업
- 재화 증가 시 숫자 바로 위 초록색 `+금액` 플로팅
- 금고 조작부 높이가 변해도 슬롯 머신 위치 고정

## 라운드 흐름

1. `일반(6회전)` 또는 `위험(3회전)` 선택
2. 선택창이 떠 있는 동안 마감 계좌 / 금고는 회색 비활성 상태
3. 방식을 고르면 선택창이 닫히고 **자금 배분** 상태 진입
4. 마감 계좌와 금고가 활성화되고, 슬롯 화면과 하단 액션바는 어두워짐
5. 납부 / 금고 기간 선택 / 금고 예치
6. 중앙의 `시작` 버튼 클릭
7. 시작 버튼은 회전 횟수를 깎지 않고 라운드 상태만 확정
8. 마감 계좌와 금고 잠금 / 슬롯과 하단 액션바 밝기 복구
9. 이후 `리롤` 버튼을 눌러 실제 회전을 소비
10. 모든 리롤을 사용하면 다음 라운드 방식 선택

즉 현재 흐름은 **방식 선택 → 자금 배분 → 시작 → 리롤**입니다.

## 마감 계좌

- 현재 마감 목표의 5% 단위로 직접 납부
- 버튼에는 `납부`만 표시
- `1회 납부금` 문구 없음
- 별도의 `마감 확정` 버튼 없음
- 목표를 모두 채우는 순간 자동 정산 후 다음 마감 진행
- 큰 금액에서도 납부액 / 목표액 줄바꿈 방지
- 방식 선택 화면에서는 회색 비활성 상태
- 자금 배분 중에는 활성 상태
- `시작` 버튼 클릭 뒤에는 회색 잠금 상태

### 납부 게이지

납부 게이지는 두 구간으로 표현됩니다.

- 이미 이전 시작 시점에 확정된 납부액: 검정/회색
- 현재 자금 배분 중 새로 납부한 금액: 빨간색

중앙 `시작` 버튼을 누르면 현재 빨간 구간이 검정/회색 확정 구간으로 합쳐집니다.
다음 라운드 준비에서 새로 납부한 부분만 다시 빨간색으로 표시됩니다.
0라운드 최종 납부에서는 추가 시작/리롤이 없으므로 새 납부 구간이 빨간색으로 유지됩니다.

## 0라운드 — 최종 납부

3라운드 종료 후:

- `현재 납부액 + 지갑 < 목표` → 즉시 게임 오버
- `현재 납부액 + 지갑 >= 목표` → **0라운드 · 최종 납부** 진입

0라운드에는 시작 버튼 / 추가 리롤 / 새 금고 예치 / 방식 선택이 없고 마감 납부만 가능합니다.
목표를 채우면 자동 정산됩니다.

## 금고

금고 설정은 라운드 선택창에 표시하지 않습니다.

방식 선택 후 자금 배분 상태에서 왼쪽 금고 카드 안의 조작부를 사용합니다.

- 2라운드 / 4라운드 중 선택
- 현재 목표의 5%씩 반복 예치
- 예치 단위 / 현재 예치금 표시
- 중앙 `시작` 버튼을 누르는 순간 금고 잠금
- 잠긴 뒤 추가 예치 / 중도출금 불가
- 실제 플레이 라운드 종료 때만 남은 라운드 감소
- 잠긴 금고는 배경이 어두워져 조작 불가 상태를 시각적으로 표시

왼쪽 금고 상태:

- 현재 금액
- 현재 이자
- `남은 라운드 2` 형태의 남은 횟수
- 티켓 진행도
- `대기 / 열림 / 준비 / 잠김` 상태

### 2라운드 상품

| 완료 라운드 | 이율 | 티켓 |
| --- | ---: | ---: |
| 1 | +15% | - |
| 2 | +15% | +1 |

### 4라운드 상품

| 완료 라운드 | 이율 | 티켓 |
| --- | ---: | ---: |
| 1 | +15% | - |
| 2 | +15% | +1 |
| 3 | +25% | - |
| 4 | +25% | +1 |

이자는 현재 금고 잔액 기준 복리이며 소수점은 버립니다.

예: `$50` 4라운드 예치 → `50 → 57 → 65 → 81 → 101`

## 화면 강조 상태

### 방식 선택 중

- 마감 계좌: 회색 / 비활성
- 금고: 회색 / 비활성
- 지갑: 정상
- 선택 오버레이에서 일반 / 위험만 선택

### 자금 배분 중

- 마감 계좌: 밝음 / 납부 가능
- 금고: 밝음 / 예치 가능
- 슬롯 화면: 어두움
- 하단 리롤/액션바: 어두움 / 비활성
- 중앙 `시작` 버튼: 활성

### 라운드 진행 중

- 마감 계좌: 회색 / 잠김
- 금고: 회색 / 잠김
- 슬롯 화면: 정상 밝기
- 하단 `리롤` 버튼: 활성
- 시작 버튼: 숨김

## 재화 숫자 연출

### 카운트업

- `requestAnimationFrame`
- 약 0.6초
- cubic ease-out
- 천 단위 콤마
- 연속 입력 시 최신 목표값으로 이어서 표시

### `+금액` 플로팅

재화가 증가하면 해당 재화 숫자 바로 위에 초록색 `+250` 같은 텍스트가 나타납니다.

- 글자 크기 소폭 확대
- 재화 숫자 바로 위에서 시작
- 위로 이동하는 거리는 짧게 조정
- 약 1.5초 동안 float-up + fade-out
- 여러 번 연속 발생하면 각각 별도 DOM 요소로 독립 애니메이션
