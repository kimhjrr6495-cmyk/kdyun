# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 7 — 첫 20개 아이템 + 실제 효과 + 패턴 단위 순차 당첨 연출 + 실시간 가치표 / v0.7.4**

현재 핵심 흐름:

1. 라운드 준비
2. 마감 납부 / 금고 / 상점 이용
3. `7회 리롤(+1T)` 또는 `3회 리롤(+3T)` 선택
4. 선택 즉시 라운드 시작
5. 납부 / 금고 / 상점 잠금
6. 하단 `리롤` 버튼으로 실제 리롤 진행
7. 여러 패턴 당첨 시 **검출된 패턴 하나씩** 순차 정산
8. 3라운드 종료 뒤 0라운드 최종 납부 또는 게임 오버 판정

## v0.7.4 패턴 단위 순차 당첨

v0.7.2의 `가로 패턴들을 한 그룹으로 동시에 정산`하는 방식을 제거했습니다.

이제 같은 종류의 패턴이라도 **패턴 하나마다 별도 이펙트와 별도 점수 지급 단계**를 거칩니다.

기본 재생 순서:

1. 가로 — 위쪽 줄부터 아래쪽 줄까지 하나씩
2. 세로 — 왼쪽 열부터 오른쪽 열까지 하나씩
3. 대각선 — 시작 위치 순서대로 하나씩
4. V
5. 역 V
6. X
7. 잭팟

예를 들어 5×3 전체가 같은 심볼이라 가로 3줄이 모두 H5라면:

```text
가로 5 · 1번째 줄
→ 가로 5 · 2번째 줄
→ 가로 5 · 3번째 줄
→ 세로 3 · 1번째 열
→ 세로 3 · 2번째 열
→ ...
→ 잭팟
```

형태로 재생됩니다.

같은 가로 줄 안에서 H3 / H4 / H5가 동시에 중복 인정되는 것은 아닙니다. 기존 판정 규칙대로 같은 연속 구간에서는 가장 큰 가로 패턴 하나만 인정합니다.

## v0.7.4 당첨 임팩트

반복 패턴은 짧고 빠르게, 큰 패턴은 더 강하게 보이도록 당첨 연출을 다시 구성했습니다.

각 패턴이 처리될 때:

- 현재 패턴에 포함된 칸만 선명하게 포커스
- 나머지 5×3 칸은 잠깐 어둡게 눌러 시선 집중
- 패턴 칸 중심을 연결하는 색상 라인 스캔
- 각 칸에 작은 노드 팝 / 테두리 펄스
- 패턴 중심에서 짧은 스파크 버스트
- 중앙에 `현재 순서 / 패턴 이름 / 심볼 / 지급액` 임팩트 배너 표시
- 패턴별 지급액이 지갑과 이번 회전 금액에 하나씩 누적
- 패턴 순서가 진행될수록 짧은 절차형 성공음의 음높이가 상승

일반 가로/세로/대각선은 빠른 기본 강도, V/역V/X는 더 강한 글로우와 스파크를 사용합니다.
잭팟은 모든 일반 패턴 정산이 끝난 마지막에 별도의 빛 확산 피니시가 한 번 더 실행됩니다.

화면 전체를 계속 흔들지는 않습니다. 반복 당첨에서도 정보가 읽히도록 **라인 / 밝기 / 스케일 / 숫자 / 사운드 타이밍**을 중심으로 구성합니다.

당첨 패턴 수가 많아지면 자동으로 1패턴당 연출 시간을 줄여, 풀보드처럼 많은 패턴이 잡혀도 지나치게 오래 끌지 않도록 합니다.

`prefers-reduced-motion` 환경에서는 애니메이션 시간을 크게 줄입니다.

## v0.7.3 실시간 심볼 가격표

오른쪽 `심볼 가격` 표는 현재 빌드 상태를 보여줍니다.

표시 순서:

`등장확률 | 심볼 | 현재 가치 | 변화식`

예시:

```text
14.3%  다이아  $9 (+3)
14.3%  세븐    $24 (×2)
14.3%  체리    $6 (×2 +2)
```

계산 규칙:

`현재 심볼 가치 = 기본 심볼 가치 × 곱보정 + 합보정`

현재 Stage 7 아이템은 주로 `+VALUE` 효과를 사용합니다. 추후 `symbol_value_mult` 타입이 추가되어도 실제 점수와 오른쪽 표가 같은 규칙으로 반영됩니다.

### 심볼 등장확률

현재 `randomSymbol()`은 7개 심볼을 균등 랜덤으로 선택합니다.

따라서 현재 실제 등장확률은 모든 심볼이:

`1 / 7 ≈ 14.3%`

입니다.

아직 실제 심볼 가중치 시스템은 구현하지 않았습니다.

## 가치 상승 색상

심볼 가치 또는 패턴 배수가 기본값보다 올라가면 현재 숫자 색이 단계적으로 더 희귀하게 보입니다.

- 기본값: 기본 텍스트색
- 소폭 강화: 그린 계열
- 중간 강화: 블루/바이올렛 계열
- 큰 강화: 골드 계열
- 매우 큰 강화: 마젠타 계열

색상은 실제 계산값 대비 기본값의 상승 비율을 기준으로 자동 결정합니다.

## 실시간 패턴 배수표

`패턴 배수`도 현재 적용값을 표시합니다.

기본값:

- 가로 3 ×1
- 가로 4 ×2
- 가로 5 ×4
- 세로 3 ×1.5
- 대각선 ×2
- V ×6
- 역 V ×6
- X ×8
- 잭팟 ×12

예를 들어 `가로 배선(×1.20)`을 보유하면:

```text
가로 3  ×1.2 (×1.2)
가로 4  ×2.4 (×1.2)
가로 5  ×4.8 (×1.2)
```

계산 규칙:

`현재 패턴 배수 = 기본 패턴 값 × 곱보정 + 합보정`

## 심볼 색상

- 체리: 레드
- 코인: 앰버
- 벨: 오렌지
- 스타: 블루
- 다이아: 바이올렛
- 크라운: 브론즈/골드
- 세븐: 마젠타

기본 셀은 옅은 색만 사용하고, 당첨 시 해당 심볼 색을 라인/테두리/스파크에도 공유합니다.

## Stage 7 아이템 시스템

상점에는 실제 효과가 연결된 첫 20개 아이템이 있습니다. 같은 아이템을 여러 개 보유하면 효과가 중첩됩니다.

기본 점수 공식:

`심볼 가치 × 심볼 배율 × 패턴 칸 수 × 패턴 기본값 × 패턴 배율 × 전체 배율`

현재 주요 아이템 예시:

- 체리 스티커 — 체리 가치 +1
- 코인 광택제 — 코인 가치 +1
- 벨 해머 — 벨 가치 +2
- 스타 렌즈 — 스타 가치 +2
- 다이아 커터 — 다이아 가치 +3
- 크라운 인장 — 크라운 가치 +3
- 세븐 스탬프 — 세븐 가치 +4
- 가로 배선 — 가로 3/4/5 ×1.20
- 세로 배선 — 세로 3 ×1.25
- 사선 자 — 대각선 ×1.30
- V 프레임 — V/역V ×1.30
- X 브릿지 — X ×1.35
- 잭팟 퓨즈 — 잭팟 ×1.50
- 시장 증폭기 — 전체 ×1.08
- 프리미엄 터미널 — 전체 ×1.15
- 개장 알림 — 첫 리롤 ×1.25
- 마감 벨 — 마지막 리롤 ×1.35
- 분산 포트폴리오 — 서로 다른 심볼 6종 이상이면 ×1.25
- 티켓 펀치 — 라운드 시작 티켓 +1
- 새로고침 쿠폰 — 상점 새로고침 비용 -1T, 최소 1T
