# DEADLINE

CloverPit 계열의 빌드 구성 재미를 참고해 확장 중인 2D 5×3 슬롯 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 10 — CONTRACTS v1.0.0**

현재 핵심 흐름:

1. 마감 2부터 새 Deadline 진입 시 계약 4개 제시
2. 계약 1개 선택 또는 계약 없이 진행
3. 라운드 준비에서 마감 계좌 납부 / 상점 이용 / 마감 3부터 금고 이용
4. `7회 리롤` 또는 `3회 리롤` 선택
5. 리롤 수익은 `이번 라운드 수익` 임시지갑에 누적
6. Luck / WILD / ERROR / Modifier / Trigger / Retrigger / 계약 효과 정산
7. 라운드 종료 시 임시지갑을 실제 지갑으로 한 번에 이동
8. 실제 라운드 종료 시 마감 계좌 이자 적용
9. 마감 성공 시 계약 보상 및 CONTRACT STREAK 처리
10. 3라운드 종료 뒤 부족하면 0라운드 최종 납부 — 단 계약이 금지할 수 있음

## v1.0.0 — Stage 10 Contracts / UI Readability Pass

### 계약 기본 규칙

- **마감 2부터 해금**
- 새 Deadline마다 **4개 계약 제시**
- 기본 제안 구성: `일반 2 / 위험 1 / 극한 1`
- 최대 1개 선택
- `계약 없이 진행` 가능
- 계약은 해당 Deadline 동안만 유지
- 성공 시 보상 지급
- 계약을 선택하지 않으면 CONTRACT STREAK 유지
- 계약을 체결하고 마감에 실패하면 STREAK 초기화

### 계약 풀 — 총 42개

6개 카테고리 × 7개 계약입니다.

#### 경제

- 긴축 재정 — 상점 새로고침 비용 +50%
- 무이자 기간 — 마감 계좌 이자 0%
- 금고 봉쇄 — 신규 금고 예치 금지
- 현금 경색 — 현재 지갑 25% 동결, 성공 시 반환
- 고비용 시장 — 상점 새로고침 비용 ×2
- 투자 우선주의 — 이번 마감에서 납부 전 상점 이용 불가
- 복리 과세 — 계좌 이자 절반 + 새로고침 비용 +25%

#### 심볼

- 희소 시장 — 💎 / 👑 / 7️⃣ 가중치 -35%
- 서민 시장 — 🍒 / 🪙 증가, 고가 심볼 감소
- 세븐 금지령 — 7️⃣ 등장 금지
- WILD 금지 — WILD 등장 금지
- 불안정 시장 — ERROR 가중치 +75% / ERROR EVENT 현금 ×2
- 카오스 시장 — 매 라운드 심볼 가중치 무작위 변화
- 사치세 — 고가 심볼 지급 감소 / 저가 심볼 지급 증가

#### 패턴

- 가로 금지
- 세로 금지
- 사선 금지
- 대형 주문 — 3칸 패턴 -50% / 5칸 이상 +25%
- 단일 정산 — 최고 지급 패턴 1개만 정산
- 분산 투자 — 같은 패턴 종류는 가장 높은 1개만 정산
- 기하학 시장 — V / 역V / X / JACKPOT만 지급

#### 상점 / 아이템

- 리롤 금지
- 폐쇄 시장 — 상점 1회만 이용 / 성공 시 다음 마감 상점 제안 +1
- 판매 금지
- 희귀품 통제 — EPIC / LEGENDARY 구매 금지
- 좁은 창고 — 보유 한도 -2
- 광택 억제 — 보유 SHINY Trait 비활성
- SHINY 구매 금지 — SHINY 구매 불가 / 성공 시 계약 보급품 선택

#### Trigger / Modifier / Retrigger

- 무반복 시장 — Retrigger 비활성
- 연쇄 차단 — Trigger 최대 4회
- 무개조 시장 — Modifier 생성 금지
- 황금 규제 — GOLDEN 효과 비활성
- 끊어진 사슬 — CHAIN 효과 비활성
- 과부하 — Trigger 최대 6회 / Trigger 지급 ×1.5
- 압축 연쇄 — Trigger 최대 3회 / Retrigger 지급 ×1.5

#### 라운드 / 마감

- 단기전 — 3회 리롤 모드만 선택
- 장기전 — 7회 리롤 모드만 선택
- 조기 마감 — Round 2까지 목표 달성 필요
- 0라운드 금지 — 최종 납부 단계 사용 불가
- 마지막 승부 — R1~2 지급 -25% / R3 +40%
- 선행 투자 — R1 패턴 지급 0 / R2~3 ×1.35
- 시장 압박 — 모든 패턴 지급 -20%

### 계약 제안 필터링

현재 빌드와 거의 관계없는 계약이 공짜 보상이 되지 않도록 후보를 걸러냅니다.

- Trigger 아이템이 없으면 Trigger 제한 계약 제외
- Retrigger 빌드가 없으면 Retrigger 전용 계약 제외
- Modifier 생성 아이템이 없으면 Modifier 제한 계약 제외
- SHINY가 없으면 SHINY Trait 비활성 계약 제외
- 아이템이 적으면 좁은 창고 제외
- 금고 해금 전에는 금고 봉쇄 제외
- WILD / ERROR 빌드가 있으면 관련 계약의 제안 가중치 증가
- 최근 제안된 계약은 다시 나올 확률 감소

### 계약 등급 / 외형

- **일반** — 회청색 / 차콜
- **위험** — 주황·적갈색 2px 테두리와 약한 glow
- **극한** — 딥레드·검붉은 배경 / 크림슨 2px 테두리 / 아주 약한 맥동 glow
- 화면 흔들림이나 왜곡은 사용하지 않음

극한 계약은 기존 금융 대시보드 UI 안에서 카드만 불길하게 튀도록 설계했습니다.

### 계약 보상

계약에 따라 다음 보상을 사용할 수 있습니다.

- 🎟️ 티켓
- 다음 마감 SHINY 확률 증가
- 다음 마감 무료 상점 새로고침
- 다음 마감 상점 제안 +1
- 다음 마감 RARE 이상 최소 1칸 보장
- 다음 마감 마감계좌 이자 보너스
- 계약 보급품 — 랜덤 아이템 3개 중 1개 선택

계약 보급품을 받을 공간이 없으면 보조 티켓 보상으로 전환합니다.

### CONTRACT STREAK

- 계약 성공: +1
- 계약 건너뛰기: 유지
- 계약 체결 후 마감 실패: 0
- 3연승 이상: 티켓 계약 보상 +20%
- 5연승 도달: 다음 마감 SHINY 확률 +3%p

### 계약 상태 UI

계약을 선택하면 상단 상태 영역에 현재 계약이 유지됩니다.

```text
▲ 불안정 시장
CONTRACT STREAK ×3
```

위험 / 극한 계약은 상단 상태칩도 해당 위험 색으로 표시합니다.

## 현재 안전장치

- JACKPOT WILD 최대 1칸
- 모든 칸 WILD만으로 패턴 생성 불가
- ERROR는 일반 패턴에 직접 참여하지 않음
- Stage 8 Trigger 최대 깊이 4
- 기본 한 원본 패턴 Trigger 최대 12회
- Stage 9 패턴 Retrigger 최대 6회
- 동일 아이템 동시 중복 보유 불가
- SHINY 복리 추가 이자 최대 +5%p
- SHINY 상인 첫 리롤 할인 최대 50%
- 계약 Trigger 제한은 기존 상한보다 낮게만 적용
- 계약 심볼 금지는 사실상 0에 가까운 가중치로 처리해 기존 랜덤 선택 fallback과 충돌하지 않음
