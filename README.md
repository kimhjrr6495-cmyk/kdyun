# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯머신 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 5 — 자금 배분 / 금고 복리 / 경고 UI / v0.5.3**

현재 구현된 것:

- 핀테크 / 트레이딩 앱 스타일 UI
- 5×3 세로 릴
- v0.1.3에서 확정한 회전 속도 유지
- 가로 3/4/5, 세로, 대각선, V, 역 V, X 패턴 판정
- 겹쳐 성립하는 패턴 전부 합산
- 15칸 전체 동일 심볼 잭팟 + 일반 패턴 동시 합산
- 일반 / 위험 라운드 선택
- 일반: 6회전 + 티켓 1
- 위험: 3회전 + 티켓 3
- 마감당 최대 3라운드
- 마감 계좌 직접 납부
- 금고 설정을 라운드 시작 화면으로 이동
- 금고 2라운드 / 4라운드 상품
- 매 라운드 복리 이자
- 금고 티켓 중간/만기 보상
- 한국어 상태 문구
- 마지막 라운드 빨간 경고 UI

## 마감 계좌

- 현재 마감 목표의 5% 단위로 직접 납부합니다.
- 납부 버튼에는 금액을 표시하지 않고 `납부`만 표시합니다.
- `1회 납부금` 안내 문구는 표시하지 않습니다.
- 기존 진행 게이지는 유지합니다.
- 납부한 돈은 다시 출금할 수 없습니다.
- 마감 계좌가 100%가 되면 `마감 확정` 버튼을 사용할 수 있습니다.
- 지갑에 목표액 이상이 있어도 마감 계좌를 채우지 않으면 미납 상태입니다.

### 경고 표시

- 1라운드: 일반 상태
- 2라운드 미납: `납부가 필요합니다`
- 마지막 3라운드 미납: `경고 · 마지막 라운드`
- 마지막 라운드에는 마감 카드 테두리와 게이지가 빨간색으로 바뀝니다.
- 상단에 `마감 위험` 상태가 표시됩니다.
- 납부에 필요한 잔액이 없으면 `잔액 부족`을 표시합니다.
- 화면 왜곡, 흔들림, 노이즈 효과는 사용하지 않습니다.

## 금고

금고 조작은 왼쪽 패널이 아니라 **라운드 시작 선택 화면 옆**에서 합니다.

왼쪽 금고 영역에는 상태만 간단하게 표시합니다.

- 금고
- 남은 라운드
- 현재 금액
- 현재 적용 이율
- 티켓 진행도

예상 금액은 표시하지 않습니다.

### 예치 방식

- 금고를 사용하지 않고 라운드를 시작할 수도 있습니다.
- 금고를 사용할 경우 2라운드 / 4라운드 중 기간을 선택합니다.
- 현재 마감 목표의 5%씩 `예치` 버튼으로 반복 예치합니다.
- 예치 버튼에는 숫자를 표시하지 않습니다.
- 라운드를 시작하는 순간 예치가 잠깁니다.
- 잠긴 뒤에는 추가 예치와 중도출금이 불가능합니다.
- 실제 라운드를 완료할 때만 금고 진행도가 1 감소합니다.

## 금고 이자 / 티켓

### 2라운드 상품

| 완료 라운드 | 적용 이율 | 티켓 |
| --- | ---: | ---: |
| 1 | +15% | - |
| 2 | +15% | +1 |

총 티켓: **+1**

### 4라운드 상품

| 완료 라운드 | 적용 이율 | 티켓 |
| --- | ---: | ---: |
| 1 | +15% | - |
| 2 | +15% | +1 |
| 3 | +25% | - |
| 4 | +25% | +1 |

총 티켓: **+2**

이자는 매 라운드 현재 금고 잔액을 기준으로 복리 계산하며 소수점은 버립니다.

예시: `$50`을 4라운드 상품에 넣으면

`50 → 57 → 65 → 81 → 101`

순서로 증가합니다.

2라운드가 끝난 뒤에는 왼쪽 금고 카드가 대략 다음 상태를 보여줍니다.

`금고 / 남은 라운드 2 / 4 / $65 + (25%) / 티켓 1 / 2`

만기 시 현재 금고 금액이 지갑으로 자동 이동합니다.

## 조기 마감 보너스

마감 계좌를 모두 채운 뒤 `마감 확정`을 누르면 아직 시작하지 않은 라운드마다 티켓 +2를 받습니다.

- 1라운드에서 확정 → 이후 2개 라운드 미사용 → +4T
- 2라운드에서 확정 → 이후 1개 라운드 미사용 → +2T
- 3라운드 → 추가 보너스 없음

## 점수 계산

`심볼 가치 × 심볼 배율 × 패턴 포함 칸 수 × 패턴 기본값 × 패턴 배율 × 전체 배율`

- V = 구성 대각선 2개 + V
- 잭팟 = 성립한 모든 일반 패턴 + 잭팟 보너스
- 같은 가로 연속 구간에서는 가장 큰 가로 패턴만 계산

- 최종 사운드
- 최종 잭팟/당첨 연출

- `game.js` — 릴 / 패턴 / 점수 / 기본 라운드 루프

- `effects.js` — 숫자 카운트업 / 민트 플래시
