# DEADLINE

CloverPit 계열의 빌드 구성 재미를 참고해 확장 중인 2D 5×3 슬롯 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 9 — 아이템 등급 / 확률 / Modifier / 재발동 / v0.9.3**

현재 핵심 흐름:

1. 라운드 준비
2. 마감 납부 / 금고 / 상점 이용
3. 상점에서 등급별 아이템 6개 확인
4. `7회 리롤` 또는 `3회 리롤` 선택
5. 선택 즉시 라운드 시작
6. 리롤 전 확률형 아이템 발동 시 오른쪽에서 아이템 카드 슬라이드 인
7. 확률형 아이템 / Luck / Modifier 생성 판정
8. 5×3 릴 회전 및 정확한 3칸 정착
9. 마지막 릴 정착 후 1프레임 안전 대기 뒤 패턴 정산
10. Modifier 효과 → Stage 8 트리거 → 패턴 재발동
11. 3라운드 종료 뒤 0라운드 최종 납부 또는 게임 오버 판정

## v0.9.3 — 심볼 희귀도 / 발동 카드 / 참조표 정리

### 심볼 기본 등장 확률

기존의 7종 균등 14.3% 추첨을 제거하고, 처음 배정된 심볼 기본 가치가 높을수록 등장 확률이 낮도록 조정했습니다.

| 심볼 | 기본 가치 | 기본 확률 |
| --- | ---: | ---: |
| 🍒 체리 | $2 | 22% |
| 🪙 코인 | $2 | 22% |
| 🔔 벨 | $3 | 18% |
| ⭐ 스타 | $4 | 14% |
| 💎 다이아 | $6 | 10% |
| 👑 크라운 | $8 | 8% |
| 7️⃣ 세븐 | $12 | 6% |

합계는 100%입니다.

Luck은 이 기본 확률을 출발점으로 고가 심볼 가중치를 올립니다. 따라서 Luck이 없을 때는 위 표 그대로이고, 풋고추 같은 Luck 효과가 발동하면 💎 / 👑 / 7️⃣ 쪽 확률이 상대적으로 상승합니다.

오른쪽 심볼 가격표도 현재 실제 확률을 실시간으로 표시합니다.

### CloverPit식 아이템 발동 카드

v0.9.2의 고정 상태창을 제거하고, 발동한 아이템 카드 자체가 머신 패널 오른쪽 바깥에서 슬라이드 인/아웃하도록 변경했습니다.

카드 표시 예시:

```text
┌─────────────────────────┐
│ 🌶️  아이템 발동  COMMON │
│      풋고추              │
│      15% 확률로 ...      │
└─────────────────────────┘
```

- 약 300px 폭의 큰 카드
- 아이콘 / 등급 / 아이템 이름 / 실제 효과 설명 표시
- 오른쪽 바깥 → 안쪽 슬라이드 인
- 읽을 수 있을 만큼 유지 후 다시 오른쪽으로 퇴장
- 여러 아이템이 발동하면 큐에서 하나씩 순서대로 표시
- 카드 애니메이션은 릴 회전과 완전히 직렬로 묶지 않아 게임 템포가 지나치게 느려지지 않도록 처리

### 심볼 가격표 정리

오른쪽 참조 레일을 넓히고 심볼 가격표의 읽기 순서를 다음처럼 변경했습니다.

```text
이모지 → 확률 → 가격
🍒      22.0%    $2
💎      10.0%    $6
7️⃣       6.0%   $12
```

기존의 왼쪽 색상 점은 제거했습니다.

넓은 화면에서 오른쪽 참조 레일은 약 205px → 285px로 넓어지고, 가격 증가식이나 성장 수치가 붙어도 한 줄이 지나치게 눌리지 않게 정렬합니다.

패턴 배수와 임시 스탯 표도 같은 레일 폭 안에서 숫자 우측 정렬을 강화했습니다.

## v0.9.0 — 대형 아이템 업데이트

아이템 풀은 총 64개입니다.

- 기존 Stage 7/8 아이템 26개

- COMMON / RARE / EPIC / LEGENDARY 등급

주요 신규 계열:

- 확률형: 풋고추, 붉은 고추, 검은 고추, 황금 고추, 확률 증폭기, 확률의 신
- 축적/구제: 고장난 자석, 잔돈통, 저금통, 재활용 회로
- 성장형: 행운 고양이, 증식 버섯, 적응형 칩
- 공간 확장: 골판지 확장팩, 자산 증명서, 과적재 선반
- 재발동: 매운 고추, 고장난 계산기, 반복 디스크, 에코 테이프, 이중 정산기, 영구기관
- Modifier: 황금 도금기, 티켓 인쇄기, 반복 스탬프, 연쇄 인장, 이중 각인 등

## Modifier 시스템

기존 7개 심볼 위에 다음 특수 속성이 붙을 수 있습니다.

- ✨ GOLDEN — 당첨 시 해당 심볼 가치 영구 성장
- 🎟️ TICKET — 당첨 시 티켓 +1, 한 리롤 최대 +2T
- ↻ REPEAT — 포함된 패턴 재발동
- ⛓️ CHAIN — 포함된 패턴의 기본 값 영구 성장

기본은 심볼 하나당 Modifier 1개이며 Legendary `이중 각인` 보유 시 최대 2개입니다.

재발동된 패턴도 Stage 8 트리거 큐를 다시 실행합니다.
