## v0.9.6 — SHINY / 코인 상점 리롤 / 다크 모드

### ✨ SHINY 아이템

상점에서 실제 보유 가능한 아이템은 **기본 4% 확률**로 SHINY가 될 수 있습니다.

- COMMON / RARE / EPIC / LEGENDARY 모두 SHINY 가능
- 구매 즉시 소비되는 보유 공간 확장 아이템은 SHINY 대상에서 제외
- SHINY 여부와 Trait은 상점 → 구매 → 보유창 → 판매 정보까지 유지
- 같은 아이템 중복 보유 금지 규칙은 그대로 유지

SHINY 아이템은 기존 희귀도 네온 위에 다음 외형이 추가됩니다.

- 일반 카드보다 두꺼운 2px 테두리
- 은은한 청록 / 보라 계열 홀로그램 그라데이션
- 카드 표면을 천천히 지나가는 약한 광택선
- `✨ SHINY` 배지
- SHINY Trait 이름 / 효과 표시
- Legendary + SHINY는 기존 금빛 네온과 홀로그램 효과가 함께 표시

### SHINY Trait 7종

한 SHINY 아이템에는 아래 부가 옵션 중 **1개**만 붙습니다.

| Trait | 효과 |
| --- | --- |
| ✨ 증폭 | 모든 패턴 지급액 +5% |
| 🍀 행운 | 매 리롤 기본 Luck +0.12 |
| 📈 복리 | 마감 계좌 라운드 이자 +1%p |
| 🔁 집착 | 마지막 당첨 패턴이 8% 확률로 1회 재발동 |
| 🃏 변칙 | WILD 등장 가중치 +0.5 |
| 🛒 상인 | 매 Deadline 첫 상점 리롤 비용 -30% |
| 🎟️ 배당 | Deadline 성공 시 티켓 +1 |

안전장치:

- `복리` SHINY의 추가 이자는 최대 +5%p
- `상인` 첫 리롤 할인은 합산 최대 50%
- `집착` 재발동도 기존 Stage 9 한 패턴 최대 6회 제한 안에서 처리

### 상점 리롤 — 티켓 → 지갑 코인

아이템 구매는 기존처럼 **티켓(T)** 을 사용하지만, 상점 새로고침은 이제 **지갑의 `$` 재화**를 사용합니다.

기본 비용:

```text
현재 Deadline 목표 × 15%
```

같은 Deadline에서 새로고침을 할 때마다 기준 비율이 5%p씩 상승합니다.

```text
15% → 20% → 25% → 30% → 35% ...
```

새 Deadline으로 이동하면 새로고침 횟수는 0으로 초기화되어 다시 15%부터 시작합니다.

예시:

| Deadline 목표 | 1회 | 2회 | 3회 | 4회 |
| ---: | ---: | ---: | ---: | ---: |
| $80 | $12 | $16 | $20 | $24 |
| $220 | $33 | $44 | $55 | $66 |
| $700 | $105 | $140 | $175 | $210 |

실제 비용은 아이템 할인 / 패널티 적용 뒤 반올림합니다.

### 상점 관련 기존 아이템 변경

- `새로고침 쿠폰` — 기존 `-1T` → **상점 새로고침 비용 -20%**
- `포인트 카드` — **3회 새로고침마다 다음 1회 무료** 유지
- `과적재 선반` — 보유 공간 +3 / **상점 새로고침 비용 +10%**

비용 계산 흐름:

```text
Deadline 목표 기준 비용
→ 같은 Deadline 리롤 횟수 상승
→ 과적재 선반 패널티
→ 새로고침 쿠폰 / SHINY 상인 할인
→ 포인트 카드 무료 판정
```

### 🌙 다크 모드

화면 상단 상태 영역에 테마 전환 버튼을 추가했습니다.

- 첫 실행 기본값: 다크 모드
- `☀️ 라이트` / `🌙 다크` 버튼으로 즉시 전환
- 선택한 테마는 `localStorage`에 저장되어 다음 접속에도 유지
- 릴 / 패널 / 마감 계좌 / 금고 / 상점 / 참조표 / 발동 카드 / Modifier / SHINY 모두 다크 모드 대응
- 기존 RARE / EPIC / LEGENDARY 네온과 SHINY 홀로그램 효과는 다크 테마에서도 유지

## v0.9.5 — 경제 시스템 재구성

### 누적 마감 계좌

마감 계좌는 런 전체에 이어지는 누적 계좌입니다.

- Deadline 성공 후 계좌 잔액이 사라지지 않음
- 다음 Deadline은 기존 잔액에서 새 목표까지 부족한 금액만 추가
- 예: 마감 1 목표 $80 달성 → 마감 2 시작 잔액도 $80

### 마감 계좌 이자

실제로 플레이한 라운드가 끝날 때마다 기본 **10% 이자**를 지급합니다.

```text
interest = floor(현재 잔액 × 적용 이자율)
```

- 0라운드 최종 납부에는 이자 없음
- 건너뛴 라운드에는 이자 없음
- SHINY `복리`로 최대 15%까지 상승 가능

### 0라운드 최종 납부 연동

0라운드 최종 납부 UI와 왼쪽 마감 계좌는 같은 잔액을 실시간으로 표시합니다.

```text
마감 계좌 $180 / 목표 $220
0라운드 최종 납부 $180 / $220
부족 $40
```

Luck이 증가하면 고가 심볼과 WILD 가중치가 상승하고 ERROR는 감소합니다.

### 🃏 WILD

WILD는 정상 심볼을 대신해 다음 패턴을 완성할 수 있습니다.

- H3 / H4 / H5
- V3
- DIAG
- V / INV_V
- X
- JACKPOT

JACKPOT은 WILD 최대 1칸만 허용합니다.

### ⚠️ ERROR

ERROR는 기본적으로 패턴을 방해하며, 패턴 판정 전 ERROR 전용 처리 순서를 거칩니다.

1. 오류 수집기
2. 디버거
3. 백업 파일
4. 불안정한 조커
5. ERROR EVENT
6. 커널 패닉 / 글리치 라우터 / 오류 증폭기
7. 최종 패턴 판정
