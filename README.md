# DEADLINE

CloverPit 계열의 빌드 구성 재미를 참고해 확장 중인 2D 5×3 슬롯 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 9 — 아이템 등급 / 확률 / Modifier / 재발동 / v0.9.0**

현재 핵심 흐름:

1. 라운드 준비
2. 마감 납부 / 금고 / 상점 이용
3. 상점에서 등급별 아이템 6개 확인
4. `7회 리롤` 또는 `3회 리롤` 선택
5. 선택 즉시 라운드 시작
6. 확률형 아이템 / Luck / Modifier 생성 판정
7. 5×3 릴 회전 및 정확한 3칸 정착
8. 실제 당첨 패턴을 하나씩 순차 정산
9. Modifier 효과 → Stage 8 트리거 → 패턴 재발동 순서로 처리
10. 3라운드 종료 뒤 0라운드 최종 납부 또는 게임 오버 판정

## v0.9.0 대형 아이템 업데이트

### 아이템 풀

기존 Stage 7/8 아이템 26개에 신규 아이템 38개를 추가해 **총 64개** 아이템 풀을 사용합니다.

기존 가치/패턴/경제/트리거 아이템도 모두 등급을 부여했습니다.

신규 아이템은 다음 계열을 포함합니다.

- 확률형: 풋고추, 붉은 고추, 검은 고추, 황금 고추, 확률 증폭기, 확률의 신
- 꽝 구제/축적: 고장난 자석, 잔돈통, 저금통, 재활용 회로
- 조건/성장: 첫 종, 외눈 렌즈, 행운 고양이, 증식 버섯, 적응형 칩
- 상점/공간: 포인트 카드, 골판지 확장팩, 자산 증명서, 과적재 선반
- 재발동: 매운 고추, 고장난 계산기, 반복 디스크, 에코 테이프, 이중 정산기, 영구기관
- Modifier 생성: 황금 도금기, 왕실 도금기, 티켓 인쇄기, VIP 인쇄기, 반복 스탬프, 연쇄 인장, 패턴 대장간, 이중 각인
- 보드 조작: 오일 캔, 시장 예언서

### 등급

모든 아이템은 네 등급 중 하나를 가집니다.

- COMMON — 기본 빌드 부품
- RARE — 빌드 방향 결정
- EPIC — 강한 시너지 / 엔진
- LEGENDARY — 규칙 자체를 바꾸는 아이템

Legendary 아이템은 동일 아이템 중복 보유를 허용하지 않습니다.

상점 등급 등장률은 Deadline 진행에 따라 달라집니다.

| Deadline | COMMON | RARE | EPIC | LEGENDARY |
| --- | ---: | ---: | ---: | ---: |
| 1~2 | 78% | 20% | 2% | 0% |
| 3~4 | 62% | 30% | 7% | 1% |
| 5~6 | 48% | 36% | 13% | 3% |
| 7~8 | 38% | 38% | 18% | 6% |
| 9~10 | 30% | 40% | 22% | 8% |

### 상점 6개 / 3×2

기존 4개 제안에서 **6개 제안**으로 증가했습니다.

PC:

```text
[ 아이템 ][ 아이템 ][ 아이템 ]
[ 아이템 ][ 아이템 ][ 아이템 ]
```

작은 화면에서는 2열 또는 1열로 자동 변경됩니다.

상점 카드에는 아이콘, 이름, 효과, 가격, 등급 배지가 표시됩니다.

### 보유 아이템 공간

기본 보유 한도는 기존처럼 **6칸**입니다.

공간 확장 아이템:

- 골판지 확장팩 — 최대치 +1
- 자산 증명서 — 최대치 +2
- 과적재 선반 — 최대치 +3 / 새로고침 비용 +1T

공간 확장 아이템은 구매 즉시 적용되고 슬롯을 차지하지 않습니다.
최대 보유 한도는 **12칸**입니다.

## Modifier 시스템

기존 7개 심볼은 그대로 유지하고 심볼 위에 특수 속성이 붙습니다.

- ✨ GOLDEN — 당첨 시 해당 심볼 가치 영구 성장
- 🎟️ TICKET — 당첨 시 티켓 +1, 한 리롤 최대 +2T
- ↻ REPEAT — 포함된 패턴 재발동
- ⛓️ CHAIN — 포함된 패턴의 기본 값 영구 성장

기본은 한 심볼당 Modifier 1개입니다.
Legendary `이중 각인`을 보유하면 최대 2개까지 붙을 수 있습니다.

Modifier는 릴 이모지를 바꾸지 않고 우측 상단 작은 배지로 표시합니다.

## 패턴 재발동

재발동은 원본 패턴을 한 번 더 지급하는 독립 시스템입니다.

재발동 원인 예시:

- ↻ REPEAT Modifier
- 매운 고추
- 고장난 계산기
- 검은 고추 / 황금 고추
- 반복 디스크
- 이중 정산기

재발동된 패턴도 **Stage 8 트리거 큐를 다시 실행**합니다.
무한 폭주 방지를 위해 한 원본 패턴의 Stage 9 재발동은 최대 6회로 제한합니다.

`에코 테이프`는 재발동 지급을 강화하고, `영구기관`은 같은 라운드에서 재발동이 이어질수록 이후 재발동 지급을 성장시킵니다.

## 확률 / Luck

v0.9.0부터 Luck은 실제 심볼 추첨 확률에 연결됩니다.

기본 상태에서는 기존처럼 7종 균등 확률입니다.
풋고추 같은 효과로 현재 리롤의 Luck이 올라가면 고가 심볼일수록 가중치가 더 크게 증가합니다.

오른쪽 심볼 가격표의 확률도 현재 Luck을 기준으로 다시 계산해 표시합니다.

확률형 시너지:

- 확률 증폭기 — 보유 확률형 효과의 발동률 ×1.50
- 확률의 신 — 확률 판정을 한 번 추가 시도
- 행운 고양이 — 확률형 효과 성공마다 자신의 지급 보너스 +2%

고추 계열에는 발동 횟수 소모, 성공 시 확률 성장, 실패 시 확률 성장 후 초기화 같은 상태가 실제 아이템 인스턴스에 저장됩니다.

## 성장 / 축적 / 구제

- 잔돈통 — 꽝마다 $2 저장, 다음 당첨에 전부 지급
- 저금통 — 매 리롤 $2 저장, 판매 시 저장금 회수
- 재활용 회로 — 꽝 2회 연속 뒤 다음 당첨 강화
- 적응형 칩 — 같은 심볼이 연속 당첨되면 심볼 가치 영구 성장
- 증식 버섯 — 한 리롤에서 많은 패턴이 나올수록 후반 패턴 지급 강화
- 오일 캔 — 일정 리롤마다 당첨되지 않은 릴 자동 재추첨
- 시장 예언서 — 패턴이 정확히 하나일 때 주변 심볼 변환

## 기존 Stage 8 트리거 연동

Stage 8의 다음 아이템은 그대로 유지됩니다.

- 에코 칩
- 가로 릴레이
- 다이아 에코
- 잭팟 축전기
- 증폭 코일
- 연쇄 계전기

Stage 9의 `복리 회로`는 같은 패턴에서 트리거 연쇄가 길어질수록 뒤쪽 트리거 지급을 강화합니다.

기존 무한 연쇄 방지:

- 최대 트리거 깊이 4
- 한 원본 패턴당 최대 트리거 발동 12회
- 같은 트리거 아이템 인스턴스 반복 발동 금지
