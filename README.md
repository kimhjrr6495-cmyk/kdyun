# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯머신 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 6 — 상점 / 시작-리롤 단일 버튼 / v0.6.0**

현재 구현된 것:

- 5×3 세로 릴과 패턴/점수 시스템
- 일반 6회전 / 위험 3회전 선택
- 마감당 플레이 라운드 3개 + 최종 납부용 0라운드
- 라운드 전 마감 납부 / 금고 설정
- 마감 확정 버튼 없이 목표 완납 시 자동 진행
- 금고 2라운드 / 4라운드 복리 상품
- 납부 게이지의 확정분 / 이번 준비분 색상 구분
- 0.6초 재화 카운트업 + 초록색 `+금액` 플로팅
- **리롤 버튼 자리를 준비 중에는 `시작`, 시작 후에는 `리롤`로 재사용**
- 라운드 종료 후 Stage 6 상점 진입
- 상점 4개 제안
- 티켓 구매 / 판매
- 상점 새로고침 비용 1T → 2T → 3T → ...
- 최대 보유 아이템 6개
- 오른쪽 아이템 서랍에 실제 보유 목록 반영

## 라운드 흐름

1. `일반(6회전)` 또는 `위험(3회전)` 선택
2. 선택창 동안 마감 계좌 / 금고는 회색 비활성
3. 방식을 고르면 **자금 배분** 진입
4. 납부 / 금고 기간 선택 / 금고 예치
5. 기존 리롤 버튼 자리가 `시작`으로 활성화
6. `시작` 클릭 — 회전 횟수는 소비하지 않음
7. 마감 계좌 / 금고 잠금
8. 같은 버튼이 `리롤`로 변경
9. 실제 리롤을 모두 사용하면 라운드 종료
10. **상점 진입**
11. 구매 / 판매 / 제안 새로고침 후 `상점 나가기`
12. 다음 라운드 방식 선택 또는 3라운드 종료 판정

즉 현재 핵심 흐름은 **방식 선택 → 자금 배분 → 시작 → 리롤 → 상점 → 다음 라운드**입니다.

## 시작 / 리롤 단일 버튼

별도의 중앙 `시작` 버튼은 제거했습니다.

하단의 같은 버튼이 상태에 따라 역할만 바뀝니다.

- 자금 배분 중: `시작`
- 라운드 진행 중: `리롤`
- 상점 / 방식 선택 중: 비활성

`시작`을 눌러도 6회/3회 리롤 횟수는 줄어들지 않습니다.
일반/위험의 티켓 보상도 방식을 고른 순간이 아니라 실제 `시작`을 누르는 순간 지급됩니다.

## 마감 계좌

- 현재 마감 목표의 5% 단위로 직접 납부
- 버튼에는 `납부`만 표시
- `1회 납부금` 문구 없음
- 목표 완납 즉시 자동 정산
- 방식 선택/상점/라운드 진행 중에는 조작 불가
- 자금 배분 중과 0라운드 최종 납부에서만 조작 가능

### 납부 게이지

- 이미 확정된 납부액: 검정/회색
- 현재 자금 배분 중 새로 납부한 금액: 빨간색
- `시작` 클릭 시 빨간 구간이 확정색으로 전환
- 0라운드에서는 마지막 신규 납부 구간이 빨간색으로 유지

## 0라운드 — 최종 납부

3라운드와 해당 상점까지 마친 뒤:

- `현재 납부액 + 지갑 < 목표` → 게임 오버
- `현재 납부액 + 지갑 >= 목표` → **0라운드 · 최종 납부**

0라운드에서는 추가 리롤 / 금고 예치 / 상점이 없고 마감 납부만 가능합니다.

## 금고

자금 배분 중 왼쪽 금고에서 사용합니다.

- 2라운드 / 4라운드
- 현재 마감 목표의 5% 단위 반복 예치
- `시작` 순간 잠금
- 실제 플레이 라운드 종료 때만 기간 감소
- 잠긴 동안 추가 예치 / 중도출금 불가

### 2라운드 상품

| 완료 라운드 | 이율 | 티켓 |
| --- | ---: | ---: |
| 1 | +15% | - |
| 2 | +15% | +1 |

### 4라운드 상품

| 완료 라운드 | 이율 | 티켓 |
| --- | ---: | ---: |
| 1 | +15% | - |
| 2 | +15% | +1 |
| 3 | +25% | - |
| 4 | +25% | +1 |

이자는 현재 금고 잔액 기준 복리이며 소수점은 버립니다.

예: `$50` 4라운드 예치 → `50 → 57 → 65 → 81 → 101`

## Stage 6 상점

실제 플레이 라운드가 끝날 때마다 상점을 한 번 거칩니다.

### 제안

- 한 번에 4개 아이템 제안
- 각 아이템은 티켓으로 구매
- 이미 구매한 제안 카드는 해당 상점에서 다시 구매할 수 없음
- 보유 아이템이 6개면 추가 구매 불가

현재 제안 아이템들은 **Stage 7 효과 구현을 위한 임시 껍데기**입니다.
구매/보유/판매 시스템은 실제로 동작하지만 아이템 능력치는 아직 적용되지 않습니다.

### 제안 새로고침

각 상점에 들어올 때 비용이 다시 1T부터 시작합니다.

- 첫 새로고침: 1T
- 두 번째: 2T
- 세 번째: 3T
- 이후 계속 +1T

새로고침하면 새로운 4개 제안을 뽑습니다.

### 보유 / 판매

- 최대 6개 보유
- 상점 화면에서 보유 아이템 판매 가능
- 현재 임시 판매가는 구매가의 절반을 기준으로 최소 1T
- 오른쪽 아이템 서랍에도 보유 목록 실시간 반영

판매 가격은 아이템 밸런스 단계에서 다시 조정할 수 있습니다.
