# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯머신 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 6 — 라운드 준비 허브 / 수동 상점 / 준비 머신 UI / v0.6.6**

현재 핵심 흐름:

1. 라운드 준비
2. 마감 납부 / 금고 / 상점 이용
3. 오른쪽 머신 전체는 회색 비활성 상태
4. 머신 패널 정중앙에서 `7회 리롤(+1T)` 또는 `3회 리롤(+3T)` 선택
5. 선택 시 납부 / 금고 잠금
6. 같은 선택을 다시 누르면 취소되고 납부 / 금고 재활성
7. 하단 `시작` 버튼으로 라운드 확정
8. 시작 후 준비 딤과 선택 UI가 사라지고 같은 버튼이 `리롤`로 변경
9. 실제 리롤 소진 후 다음 라운드 준비
10. 3라운드 종료 뒤에는 상점 없이 0라운드 최종 납부 또는 게임 오버 판정

## 라운드 준비 화면 — v0.6.6

준비 중에는 오른쪽 `5 × 3 시장 연동 릴` 머신을 하나의 비활성 플레이 영역으로 취급합니다.

- 릴 / 이번 회전 정산 / 패턴 정보 / 설명 영역을 회색으로 딤 처리
- 패턴 테스트 / 심볼 정보는 조작 불가
- 예외적으로 `7회/3회 선택`, `시작`, `상점`만 준비 중 조작 가능
- 선택 UI는 릴 첫 칸이나 15칸 영역 기준이 아니라 **오른쪽 머신 패널 전체의 시각적 중앙**에 표시

선택 규칙:

- `7회 리롤` → 실제 리롤 7회 / 시작 시 티켓 +1
- `3회 리롤` → 실제 리롤 3회 / 시작 시 티켓 +3
- 선택 전 `시작` 비활성
- 선택 후 `시작` 검정 활성
- 같은 카드를 다시 누르면 선택 취소

## 상점 버튼 상태

상점은 라운드 준비 중에만 수동으로 열 수 있습니다.

- 준비 중 사용 가능 → **검정 배경 + 흰 글씨**
- 진행 중 / 0라운드 등 사용 불가 → 흰색 배경 + 흐린 글씨
- 기존 준비 단계 CSS의 버튼 opacity/grayscale 규칙보다 v0.6.6 상태 규칙을 우선 적용

상점 모달:

- `마감 N`, `라운드 N` 같은 진행 정보 없음
- 아이템 4개 제안
- 티켓으로 구매
- 제안 새로고침 비용 1T → 2T → 3T → ...
- 우측 상단 작은 `×`
- 모달 바깥 배경 클릭으로 닫기
- `ESC`로 닫기
- 구매 목록 바로 아래에 큰 `보유 아이템 0/6` 영역 표시

## 지갑 / 티켓

상단 상태바에는 별도 티켓 표시가 없습니다.

지갑 카드 한 줄에서 돈과 티켓을 함께 표시합니다.

```text
$ 1,250                         T 7
```

## 마감 계좌 / 금고

- 현재 마감 목표의 5% 단위로 직접 납부
- 목표 완납 시 자동 정산
- 리롤 횟수를 고르기 전 준비 상태에서 납부 / 금고 조작 가능
- 7회/3회 선택 시 잠금
- 선택 취소 시 다시 사용 가능
- 실제 시작 순간 금고 예치 확정
- 실제 플레이 라운드 종료 때만 금고 기간 감소

금고 상품:

- 2라운드: +15% / +15%, 만기 티켓 +1
- 4라운드: +15% / +15% / +25% / +25%, 2·4라운드 티켓 +1

## 보유 아이템 / 판매

상점을 열지 않은 평상시 화면에는 보유 아이템 트레이를 표시하지 않습니다.

보유 아이템은 상점 안에서만 크게 확인합니다.

- 최대 6개 보유
- 구매 즉시 상점 아래 보유 영역에 반영
- 보유 아이템 클릭 시 중앙 대형 판매 모달
- 이름 / 효과 / 구매가 / 판매가 표시
- 현재 임시 판매가는 구매가의 절반 기준, 최소 1T

실제 아이템 효과는 Stage 7에서 연결합니다.
