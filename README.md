# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯머신 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 5 — 납부 구간 / 0라운드 / 금고 잠금 / 재화 연출 / v0.5.5**

현재 구현된 것:

- 핀테크 / 트레이딩 앱 스타일 UI
- 5×3 세로 릴
- v0.1.3에서 확정한 회전 속도 유지
- 가로 3/4/5, 세로, 대각선, V, 역 V, X 패턴 판정
- 겹쳐 성립하는 패턴 전부 합산
- 15칸 전체 동일 심볼 잭팟 + 일반 패턴 동시 합산
- 일반 6회전 / 위험 3회전 라운드 선택
- 마감당 플레이 라운드 3개 + 최종 납부용 0라운드
- 마감 계좌 직접 납부
- 마감 확정 버튼 제거 / 목표 납부 완료 시 자동 진행
- 금고 2라운드 / 4라운드 상품과 복리 이자
- 금고 잠금 UI
- 재화 0.6초 ease-out 카운트업
- 재화 증가 시 초록색 `+금액` 플로팅
- 마지막 라운드 / 최종 납부 빨간 경고 UI

## 납부 가능 시점

납부는 아무 때나 할 수 없습니다.

1. 라운드 선택 화면에서 `일반(6회전)` 또는 `위험(3회전)`을 선택
2. 선택 직후부터 첫 회전을 누르기 전까지 `납부 가능`
3. 첫 회전을 누르는 순간 해당 라운드가 시작되고 `납부 잠김`
4. 해당 라운드의 모든 회전이 끝난 뒤 다음 라운드 방식을 고르면 다시 첫 회전 전 납부 구간이 열림

즉 **방식 선택 후 첫 회전 전**이 라운드 시작 전 납부 구간입니다.

마감 목표의 5% 단위로 직접 납부하며, 납부한 돈은 다시 회수할 수 없습니다.

## 0라운드 — 최종 납부

기존에는 3라운드가 끝나면 곧바로 성공/실패를 판정했지만 v0.5.5부터 마지막 납부 기회가 있습니다.

3라운드 종료 후:

- `현재 납부액 + 지갑 < 목표` → 즉시 게임 오버
- `현재 납부액 + 지갑 >= 목표` → **0라운드 · 최종 납부** 진입

0라운드에서는:

- 추가 회전 없음
- 새 금고 예치 없음
- 라운드 방식 선택 없음
- 마감 계좌 납부만 가능

목표 금액을 모두 채우면 별도의 `마감 확정` 버튼 없이 자동으로 해당 마감을 정산하고 다음 마감으로 이동합니다.

## 마감 계좌 UI / 경고

- 납부 버튼에는 `납부`만 표시
- `1회 납부금` 문구 없음
- 진행 게이지 유지
- 큰 금액에서도 납부액 / 목표액 줄바꿈 방지
- 방식 선택 전: `납부 대기`
- 방식 선택 후 첫 회전 전: `납부 가능`
- 라운드 진행 중: `납부 잠김`
- 0라운드: `최종 납부`
- 마지막 라운드/0라운드는 빨간 테두리와 경고 문구 사용
- 화면 흔들림, 왜곡, 노이즈는 사용하지 않음

## 자동 마감 정산

`마감 확정` 버튼은 화면에서 제거했습니다.

납부액이 목표에 도달하는 즉시:

- 현재 마감 정산
- 아직 시작하지 않은 라운드가 있으면 기존 미사용 라운드 티켓 보너스 계산
- 짧은 완료 표시 후 자동으로 다음 마감으로 이동

0라운드에서 완납한 경우 미사용 라운드 보너스는 없습니다.

## 금고

금고 설정은 라운드 선택 화면 옆에서 합니다.

- 2라운드 / 4라운드 중 선택
- 현재 마감 목표의 5%씩 반복 예치
- 라운드 방식을 선택하면 금고가 잠김
- 잠긴 뒤 추가 예치 / 중도출금 불가
- 실제 플레이 라운드 종료 때만 남은 라운드 감소

왼쪽 금고 상태에는 다음만 간단히 표시합니다.

- 현재 금액
- `현재 이자 15%` 같은 이율
- `남은 라운드 2`
- 티켓 진행도
- `비어 있음 / 잠금 준비 / 잠김`

### 2라운드 상품

| 완료 라운드 | 이율 | 티켓 |
| --- | ---: | ---: |
| 1 | +15% | - |
| 2 | +15% | +1 |

### 4라운드 상품

| 완료 라운드 | 이율 | 티켓 |
| --- | ---: | ---: |
| 1 | +15% | - |
| 2 | +15% | +1 |
| 3 | +25% | - |
| 4 | +25% | +1 |

이자는 현재 금고 잔액 기준 복리이며 소수점은 버립니다.

예: `$50` 4라운드 예치 → `50 → 57 → 65 → 81 → 101`

## 재화 숫자 연출

### 카운트업

- `requestAnimationFrame`
- 약 0.6초
- cubic ease-out
- 천 단위 콤마
- 연속 입력 시 최신 목표값으로 이어서 표시

적용 위치:

- 슬롯 보상 → 지갑
- 마감 계좌 납부
- 금고 예치
- 금고 라운드 이자
- 금고 만기 → 지갑

### `+금액` 플로팅

재화가 증가할 때 해당 숫자 위에 초록색 `+250` 같은 텍스트가 나타납니다.

- 약 1.5초 지속
- CSS `opacity` + `transform: translateY` 기반 float-up / fade-out
- 여러 번 연속 발생하면 매번 별도 DOM 요소를 생성해 독립적으로 애니메이션
- 슬롯 수익, 마감 계좌 증가, 금고 예치, 금고 이자, 만기 지갑 지급 등에 사용
