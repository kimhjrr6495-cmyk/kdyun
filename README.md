# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯머신 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 2 — 패턴 판정**  
**버전: v0.2.0**

현재 구현된 것:

- 핀테크 / 트레이딩 앱 스타일 UI
- 5×3 세로 릴 구조
- v0.1.3에서 확정한 릴 회전감 유지
- 회전 버튼 / Space 키 입력
- 랜덤 심볼 결과 생성
- 가로 3 / 4 / 5 판정
- 세로 3 판정
- 양방향 3칸 대각선 판정
- V / 역 V / X 판정
- 큰 가로 패턴 안의 작은 가로 패턴 중복 제거
- 감지된 패턴의 임시 민트색 칸 강조
- 감지된 패턴 이름 표시
- Stage 2 전용 패턴 테스트 버튼

## 패턴 정의

- 가로 3 ×1
- 가로 4 ×2
- 가로 5 ×4
- 세로 3 ×1.5
- 대각선 ×2
- V ×6
- 역 V ×6
- X ×8

배율 값은 현재 데이터만 정의되어 있고 실제 점수 계산은 Stage 3에서 연결합니다.

## Stage 2 테스트 버튼

`패턴 테스트` 버튼을 누르면 아래 샘플을 순서대로 확인할 수 있습니다.

1. 가로 3
2. 가로 4
3. 가로 5
4. 세로 3
5. 대각선
6. V
7. 역 V
8. X

이 버튼은 판정 검수용 임시 기능이며 후속 단계에서 제거할 수 있습니다.

## 아직 구현하지 않은 것

- 실제 점수 계산
- 지갑 증가
- 마감 / 라운드 실제 로직
- 상점
- 아이템 효과
- 숫자 카운트업
- 최종 당첨 강조 / 민트 플래시
- 릴 정지 사운드
- 위험 연출

## 파일 구조

- `index.html` — 메인 화면 구조
- `style.css` — UI 및 Stage 2 임시 패턴 강조
- `data.js` — 심볼 / 릴 / 패턴 정의
- `game.js` — 릴 회전 + 패턴 판정
- `effects.js` — 후속 시각 / 사운드 이펙트 전용
