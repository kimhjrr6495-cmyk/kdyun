## v0.8.6 당첨 연출 정리

### 당첨 테두리 잘림 수정

릴 외곽의 `overflow:hidden`과 둥근 모서리에 닿는 맨 위 / 아래 / 양끝 심볼에서 당첨 테두리가 잘려 보이지 않도록 수정했습니다.

기존처럼 셀 가장자리에 바로 테두리를 붙이지 않고, 당첨선 자체를 셀 안쪽으로 밀어 넣어 그립니다.

```text
셀 바깥 경계
└─ 3px 안쪽 여백
   └─ 당첨 테두리
```

따라서 가장자리 심볼도 네 방향 당첨선이 모두 보이도록 처리합니다.

### 릴 정지 검은 테두리 제거

기존 기본 CSS의 `.reel-settled { border-color: var(--ink); }` 때문에 각 릴이 멈출 때 잠깐 검은 외곽선이 나타났습니다.

v0.8.6에서는 이 정지 확인용 외곽선을 제거했습니다.

이제 흐름은:

```text
릴 회전
→ 각 릴 정지
→ 검은 정지 체크 없음
→ 모든 릴 정착
→ 실제 당첨 패턴만 표시
```

입니다.

## v0.8.5 릴 미니멀 표시

릴 안에는 심볼 이름 텍스트를 표시하지 않고 이모지만 사용합니다.

- 🍒 체리
- 🪙 코인
- 🔔 벨
- ⭐ 스타
- 💎 다이아
- 👑 크라운
- 7️⃣ 세븐

릴 기본 셀의 심볼별 배경색은 제거되어 모든 심볼이 같은 중립 배경을 사용합니다.
심볼별 색상은 당첨 라인 / 테두리 / 스파크 같은 피드백에만 사용합니다.

## v0.8.4 가독성 개선

오른쪽 `심볼 가격` 표는 기존 구조를 유지합니다.

`등장확률 | 심볼 | 현재 가치 | 변화식`

심볼 이름 칸만 릴과 동일한 이모지로 표시합니다.

패턴 배수표의 `가로 3`, `가로 4`, `세로 3`, `V`, `X`, `잭팟` 구조는 그대로 유지합니다.

## v0.8.3 릴 정지 위치 정밀 수정

실제 `.reel-symbol` DOM 높이를 직접 측정해 회전 이동 거리를 계산합니다.

릴 내부 높이와 실제 심볼 3칸 높이를 정확히 맞추고, 최종 3칸 DOM이 화면에 그려진 뒤에만 패턴 판정을 시작합니다.

## 아이템 설명 규칙

플레이어에게 보이는 설명은 `점수`보다 실제 의미에 맞는 **기본 가치 / 지급액 / 추가 지급** 표현을 사용합니다.

예시:

- 체리 스티커 — `체리 기본 가치 +1`
- 다이아 커터 — `다이아 기본 가치 +3`
- 가로 배선 — `가로 패턴 지급액 증가`
- 잭팟 퓨즈 — `잭팟 지급액 증가`
- 에코 칩 — `패턴 당첨 시 추가 지급`
- 티켓 펀치 — `라운드 시작 시 티켓 +1`

숫자가 없으면 효과를 이해하기 어려운 `+1`, `-1T`, `6종 이상` 같은 핵심 수치는 유지합니다.

## 리롤 선택 티켓 보상

`티켓 펀치` 같은 라운드 시작 티켓 보너스를 보유하면 준비 화면의 보상 표시도 실시간으로 바뀝니다.

기본:

```text
7회 리롤 — 티켓 +1
3회 리롤 — 티켓 +3
```

티켓 펀치 1개:

```text
7회 리롤 — 티켓 +2
3회 리롤 — 티켓 +4
```

## Stage 8 트리거 큐

패턴 하나가 정산되면 `PATTERN_SETTLED` 이벤트가 생성됩니다.
보유한 트리거 아이템이 조건을 만족하면 추가 지급을 만들고, 그 지급은 다시 `BONUS_GRANTED` 이벤트를 만들 수 있습니다.

무한 연쇄 방지:

- 최대 연쇄 깊이 4
- 한 원본 패턴당 최대 트리거 발동 12회
- 같은 아이템 인스턴스 반복 발동 금지

현재 Stage 8 연쇄 아이템:

- 에코 칩
- 가로 릴레이
- 다이아 에코
- 잭팟 축전기
- 증폭 코일
- 연쇄 계전기

기존 Stage 7 아이템 20개를 포함해 현재 상점 풀은 총 26개입니다.

## 패턴 정산 순서

1. 가로 — 위쪽 줄부터 아래쪽 줄
2. 세로 — 왼쪽 열부터 오른쪽 열
3. 대각선
4. V
5. 역 V
6. X
7. 잭팟
