# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 8 — 트리거 / 연쇄 시스템 / v0.8.1**

현재 핵심 흐름:

1. 라운드 준비
2. 마감 납부 / 금고 / 상점 이용
3. `7회 리롤` 또는 `3회 리롤` 선택
4. 선택 즉시 라운드 시작
5. 검출된 패턴을 하나씩 순차 정산
6. 각 패턴 정산 직후 Stage 8 트리거 큐 실행
7. 아이템 발동 → 추가 지급 → 다른 아이템 반응 → 다음 패턴
8. 3라운드 종료 뒤 0라운드 최종 납부 또는 게임 오버 판정

## v0.8.1 아이템 설명 간소화

상점과 보유 아이템에 보이는 설명을 더 짧게 정리했습니다.

숫자가 없어도 효과를 충분히 이해할 수 있는 아이템은 세부 퍼센트/배율을 설명에서 제거합니다.

예시:

- 에코 칩 — `패턴 당첨 시 추가 지급`
- 가로 릴레이 — `가로 패턴 당첨 시 추가 지급`
- 다이아 에코 — `다이아 패턴 당첨 시 추가 지급`
- 잭팟 축전기 — `잭팟 정산 시 추가 지급`
- 증폭 코일 — `트리거 보너스 추가 증폭`
- 연쇄 계전기 — `연쇄 발동 시 추가 지급`
- 가로 배선 — `가로 패턴 강화`
- X 브릿지 — `X 패턴 강화`

반대로 숫자가 없으면 효과 크기나 조건 자체를 알 수 없는 설명은 숫자를 유지합니다.

- 체리 스티커 — `체리 가치 +1`
- 다이아 커터 — `다이아 가치 +3`
- 분산 포트폴리오 — `심볼 6종 이상이면 점수 강화`
- 티켓 펀치 — `라운드 시작 시 티켓 +1`
- 새로고침 쿠폰 — `상점 새로고침 비용 -1T`

실제 내부 밸런스 수치와 계산식은 그대로 유지하며, 이번 변경은 플레이어에게 보여주는 설명 문구만 단순화합니다.

## v0.8.1 리롤 선택 티켓 보상 표시

`티켓 펀치`처럼 라운드 시작 보상 티켓을 증가시키는 아이템을 보유하면 라운드 준비 화면의 리롤 선택 버튼도 실제 획득량을 즉시 표시합니다.

기본:

```text
7회 리롤 — 티켓 +1
3회 리롤 — 티켓 +3
```

티켓 펀치 1개 보유:

```text
7회 리롤 — 티켓 +2
3회 리롤 — 티켓 +4
```

티켓 펀치 2개 보유:

```text
7회 리롤 — 티켓 +3
3회 리롤 — 티켓 +5
```

아이템 구매/판매 직후 `updateAllUI()`에서 현재 보유 아이템을 다시 계산하므로 표시가 즉시 갱신됩니다. 실제 라운드 시작 시 지급되는 티켓 계산은 기존 Stage 7 로직과 동일합니다.

## Stage 8 트리거 큐

패턴 하나가 정산되면 `PATTERN_SETTLED` 이벤트가 생성됩니다. 보유한 트리거 아이템이 조건을 만족하면 순서대로 발동하며 추가 지급을 만들고, 그 지급은 다시 `BONUS_GRANTED` 이벤트를 생성할 수 있습니다.

예시:

```text
다이아 가로 5 정산
→ 에코 칩 발동
→ 가로 릴레이 발동
→ 다이아 에코 발동
→ 증폭 코일 반응
→ 연쇄 계전기 발동
→ 다음 패턴 정산
```

무한 연쇄 방지:

- 최대 연쇄 깊이: 4
- 한 원본 패턴당 최대 트리거 발동: 12회
- 같은 아이템 인스턴스의 반복 발동 금지

## Stage 8 신규 연쇄 아이템 6개

| 아이템 | 가격 | 화면 설명 |
| --- | ---: | --- |
| 에코 칩 | 3T | 패턴 당첨 시 추가 지급 |
| 가로 릴레이 | 3T | 가로 패턴 당첨 시 추가 지급 |
| 다이아 에코 | 4T | 다이아 패턴 당첨 시 추가 지급 |
| 잭팟 축전기 | 5T | 잭팟 정산 시 추가 지급 |
| 증폭 코일 | 4T | 트리거 보너스 추가 증폭 |
| 연쇄 계전기 | 4T | 연쇄 발동 시 추가 지급 |

기존 Stage 7 아이템 20개는 그대로 유지되며, 상점은 총 26개 풀에서 4개를 제안합니다.

## 패턴 정산 순서

같은 종류라도 패턴 하나씩 처리합니다.

1. 가로 — 위쪽 줄부터 아래쪽 줄
2. 세로 — 왼쪽 열부터 오른쪽 열
3. 대각선
4. V
5. 역 V
6. X
7. 잭팟

각 패턴의 기본 지급이 끝난 뒤 그 패턴에 대한 트리거 큐가 전부 끝나야 다음 패턴으로 이동합니다.

## 당첨 연출 / 잭팟

현재 패턴 정산 시 해당 패턴 칸만 포커스하고, 패턴 모양 라인 스캔 / 노드 / 테두리 펄스 / 짧은 스파크 / 중앙 지급액 배너를 사용합니다.

잭팟은 화면 중앙 방사형 flare를 사용하지 않습니다. `reels-shell` 이중 테두리, 5개 릴 테두리 동시 강조, 심볼 색 기반 글로우, 상승 차임 + 마지막 코드 방식으로 처리합니다.

## 실시간 심볼 가치 / 패턴 배수

오른쪽 심볼 표는:

`등장확률 | 심볼 | 현재 가치 | 변화식`

형식입니다.

현재 심볼 추첨은 아직 7종 균등 랜덤이므로 각 심볼 실제 등장확률은 약 `14.3%`입니다.

계산 규칙:

`현재 심볼 가치 = 기본 심볼 가치 × 곱보정 + 합보정`

`현재 패턴 배수 = 기본 패턴 값 × 곱보정 + 합보정`

강화된 값은 상승 비율에 따라 그린 → 바이올렛 → 골드 → 마젠타 계열로 표시됩니다.
