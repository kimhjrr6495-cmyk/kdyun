# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 8 — 트리거 / 연쇄 시스템 / v0.8.4**

현재 핵심 흐름:

1. 라운드 준비
2. 마감 납부 / 금고 / 상점 이용
3. `7회 리롤` 또는 `3회 리롤` 선택
4. 선택 즉시 라운드 시작
5. 실제 심볼 한 칸 높이를 기준으로 릴 회전
6. 모든 릴이 정확한 3칸 위치에 정착한 뒤 패턴 판정
7. 검출된 패턴을 하나씩 순차 정산
8. 각 패턴 직후 Stage 8 트리거 큐 실행
9. 3라운드 종료 뒤 0라운드 최종 납부 또는 게임 오버 판정

## v0.8.4 가독성 개선

이번 버전은 릴과 오른쪽 심볼 가격표를 더 빠르게 알아볼 수 있도록 정리합니다.

### 릴 심볼

기존 `CH / CO / BL / ST / DM / CR / 7` 텍스트 코드 대신 이모지를 사용합니다.

- 체리 — 🍒
- 코인 — 🪙
- 벨 — 🔔
- 스타 — ⭐
- 다이아 — 💎
- 크라운 — 👑
- 세븐 — 7️⃣

릴의 `data-symbol`, 좌표 데이터, 패턴 판정 방식은 그대로 유지하므로 이번 변경은 표시 방식만 바꿉니다.

각 이모지 아래에는 작은 한국어 심볼 이름만 표시합니다.

### 릴 내부 구분선

5개의 세로 릴 자체는 계속 서로 분리되어 있습니다.

다만 하나의 세로 릴 안에서 위 / 가운데 / 아래 심볼을 나누던 가로 구분선은 제거했습니다.

즉 한 릴은 하나의 큰 카드처럼 보이고, 그 안에 3개 심볼이 자연스럽게 배치됩니다.

### 심볼 가격표

오른쪽 `심볼 가격` 표의 구조는 변경하지 않습니다.

기존 형식:

`등장확률 | 심볼 | 현재 가치 | 변화식`

을 그대로 유지하며, 심볼 이름 칸만 릴과 동일한 이모지로 교체합니다.

예시:

```text
14.3%   🍒   $2
14.3%   💎   $9 (+3)
14.3%   👑   $8
```

확률, 현재 가치, 아이템 보정식, 가치 상승 색상은 기존 v0.7.3 시스템을 그대로 사용합니다.

### 패턴 배수표

`가로 3`, `가로 4`, `세로 3`, `V`, `X`, `잭팟` 등 기존 패턴 배수표는 **이번 버전에서 변경하지 않습니다.**

## v0.8.3 릴 정지 위치 정밀 수정

기존에는 실제 심볼 한 칸이 94px인데 `reel.clientHeight / 3` 계산 결과가 약 93.33px이 되어 긴 회전 track에서 위치 오차가 누적될 수 있었습니다.

v0.8.3부터는 실제 `.reel-symbol` DOM 높이를 직접 측정해 이동 거리를 계산합니다.

또한 릴 내부 높이를 심볼 3칸과 정확히 맞추고, 최종 3칸 DOM이 실제 화면에 그려진 뒤에만 패턴 판정을 시작합니다.

## 아이템 설명 규칙

플레이어에게 보이는 설명은 `점수`보다 실제 의미에 맞는 **기본 가치 / 지급액 / 추가 지급** 표현을 사용합니다.

예시:

- 체리 스티커 — `체리 기본 가치 +1`
- 다이아 커터 — `다이아 기본 가치 +3`
- 가로 배선 — `가로 패턴 지급액 증가`
- 잭팟 퓨즈 — `잭팟 지급액 증가`
- 에코 칩 — `패턴 당첨 시 추가 지급`
- 티켓 펀치 — `라운드 시작 시 티켓 +1`

숫자가 없으면 효과를 이해하기 어려운 `+1`, `-1T`, `6종 이상` 같은 핵심 수치는 유지합니다.

## 리롤 선택 티켓 보상

`티켓 펀치` 같은 라운드 시작 티켓 보너스를 보유하면 준비 화면의 보상 표시도 실시간으로 바뀝니다.

기본:

```text
7회 리롤 — 티켓 +1
3회 리롤 — 티켓 +3
```

티켓 펀치 1개:

```text
7회 리롤 — 티켓 +2
3회 리롤 — 티켓 +4
```

## Stage 8 트리거 큐

패턴 하나가 정산되면 `PATTERN_SETTLED` 이벤트가 생성됩니다.
보유한 트리거 아이템이 조건을 만족하면 추가 지급을 만들고, 그 지급은 다시 `BONUS_GRANTED` 이벤트를 만들 수 있습니다.

무한 연쇄 방지:

- 최대 연쇄 깊이 4
- 한 원본 패턴당 최대 트리거 발동 12회
- 같은 아이템 인스턴스 반복 발동 금지

현재 Stage 8 연쇄 아이템:

- 에코 칩
- 가로 릴레이
- 다이아 에코
- 잭팟 축전기
- 증폭 코일
- 연쇄 계전기

기존 Stage 7 아이템 20개를 포함해 현재 상점 풀은 총 26개입니다.

## 패턴 정산 순서

같은 종류의 패턴도 하나씩 처리합니다.

1. 가로 — 위쪽 줄부터 아래쪽 줄
2. 세로 — 왼쪽 열부터 오른쪽 열
3. 대각선
4. V
5. 역 V
6. X
7. 잭팟

각 패턴의 지급과 해당 패턴의 트리거 연쇄가 모두 끝난 뒤 다음 패턴으로 넘어갑니다.

## 당첨 연출 / 잭팟

일반 패턴은 현재 패턴 칸 포커스, 패턴 라인 스캔, 노드, 짧은 스파크, 중앙 지급액 배너를 사용합니다.

잭팟은 화면 중앙 방사형 flare를 사용하지 않고 `reels-shell` 이중 테두리, 5개 릴 테두리 강조, 심볼 색 글로우, 상승 차임 방식으로 처리합니다.
