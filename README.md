## v0.8.3 릴 정지 위치 정밀 수정

v0.8.2에서 판정 전 렌더링 대기를 추가했지만, 실제 원인은 릴 이동거리 계산에도 있었습니다.

전역 CSS는 `box-sizing: border-box`이고 기본 릴 한 칸 높이는 `94px`입니다. 기존 `.reel` 높이는 `94px × 3 = 282px`였지만 위/아래 1px 테두리가 그 높이 안에 포함되므로 실제 `clientHeight`는 280px이었습니다.

기존 애니메이션은:

`reel.clientHeight / 3 = 약 93.33px`

을 한 칸 높이로 사용했습니다. 실제 심볼 한 칸은 94px이므로 긴 회전 track에서 이 차이가 누적되어 정지 직전에 이전 심볼 일부가 릴 위쪽에 남아 보일 수 있었습니다.

v0.8.3에서는 다음과 같이 변경했습니다.

```text
애니메이션용 심볼 DOM 생성
→ 실제 .reel-symbol 높이 직접 측정
→ 실제 높이 × 이동 칸 수로 정확한 transform 거리 계산
→ 정확한 끝점까지 이동
→ 최종 3칸 DOM으로 교체
→ transform 0 / top 0 강제
→ 실제 화면에 한 프레임 그린 뒤 정지 완료
→ v0.8.2의 전체 릴 최종 정규화
→ 패턴 판정
```

또한 릴 프레임 높이를 `94px × 3 + 테두리 2px`로 맞춰 내부 `clientHeight`와 실제 심볼 3칸 높이가 정확히 일치하도록 했습니다.

행 구분선 위치도 실제 94px / 188px 경계에 맞춥니다.

## v0.8.2 아이템 설명 용어

아이템 설명에서 `점수`라는 표현을 최대한 제거하고, 실제 게임 재화/지급 의미에 맞게 **기본 가치 / 지급액 / 추가 지급** 중심으로 정리했습니다.

예시:

- 체리 스티커 — `체리 기본 가치 +1`
- 다이아 커터 — `다이아 기본 가치 +3`
- 가로 배선 — `가로 패턴 지급액 증가`
- 잭팟 퓨즈 — `잭팟 지급액 증가`
- 시장 증폭기 — `모든 당첨 지급액 증가`
- 개장 알림 — `첫 리롤 지급액 증가`
- 에코 칩 — `패턴 당첨 시 추가 지급`
- 잭팟 축전기 — `잭팟 정산 시 추가 지급`

숫자가 없으면 효과를 이해하기 어려운 `+1`, `-1T`, `6종 이상` 같은 핵심 수치는 계속 표시합니다.

## v0.8.2 개발 테스트 버튼

지갑 영역에 개발 테스트 버튼 2개가 있습니다.

- `TEST +$100` — 지갑에 $100 추가
- `TEST +5T` — 티켓 5개 추가

두 버튼 모두 개발 중 마감/상점/아이템 흐름 테스트용이며 최종 빌드 전에 제거할 예정입니다.

## v0.8.1 리롤 선택 티켓 보상 표시

`티켓 펀치`처럼 라운드 시작 보상 티켓을 증가시키는 아이템을 보유하면 리롤 선택 버튼도 실제 획득 예정량을 표시합니다.

기본:

```text
7회 리롤 — 티켓 +1
3회 리롤 — 티켓 +3
```

티켓 펀치 1개:

```text
7회 리롤 — 티켓 +2
3회 리롤 — 티켓 +4
```

아이템 구매/판매 후 즉시 다시 계산합니다.

## Stage 8 트리거 큐

패턴 하나가 정산되면 `PATTERN_SETTLED` 이벤트가 생성됩니다.
보유한 트리거 아이템이 조건을 만족하면 추가 지급을 만들고, 그 지급은 다시 `BONUS_GRANTED` 이벤트를 만들 수 있습니다.

무한 연쇄 방지:

- 최대 연쇄 깊이: 4
- 한 원본 패턴당 최대 트리거 발동: 12회
- 같은 아이템 인스턴스 반복 발동 금지

### Stage 8 연쇄 아이템 6개

| 아이템 | 가격 | 화면 설명 |
| --- | ---: | --- |
| 에코 칩 | 3T | 패턴 당첨 시 추가 지급 |
| 가로 릴레이 | 3T | 가로 패턴 당첨 시 추가 지급 |
| 다이아 에코 | 4T | 다이아 패턴 당첨 시 추가 지급 |
| 잭팟 축전기 | 5T | 잭팟 정산 시 추가 지급 |
| 증폭 코일 | 4T | 트리거 보너스 추가 지급 |
| 연쇄 계전기 | 4T | 연쇄 발동 시 추가 지급 |

기존 Stage 7 아이템 20개를 포함해 현재 상점 풀은 총 26개입니다.

## 패턴 정산 순서

같은 종류의 패턴도 하나씩 처리합니다.

1. 가로 — 위쪽 줄부터 아래쪽 줄
2. 세로 — 왼쪽 열부터 오른쪽 열
3. 대각선
4. V
5. 역 V
6. X
7. 잭팟

각 패턴의 지급과 해당 패턴의 트리거 연쇄가 모두 끝난 뒤 다음 패턴으로 넘어갑니다.

## 당첨 연출 / 잭팟

일반 패턴:

- 현재 패턴 칸 포커스
- 나머지 칸 일시적으로 어둡게 처리
- 패턴 라인 스캔
- 노드 / 테두리 펄스 / 스파크
- 중앙 지급액 배너
- 지급액 / 지갑 순차 누적

잭팟은 화면 중앙 방사형 flare를 사용하지 않습니다.
`reels-shell` 이중 테두리, 5개 릴 테두리 강조, 심볼 색 글로우, 상승 차임 + 마지막 코드 방식입니다.

## 실시간 심볼 가치 / 패턴 배수

오른쪽 심볼 표:

`등장확률 | 심볼 | 현재 가치 | 변화식`

현재 심볼 추첨은 7종 균등 랜덤이므로 실제 등장확률은 각 약 `14.3%`입니다.

계산 규칙:

`현재 심볼 가치 = 기본 심볼 가치 × 곱보정 + 합보정`

`현재 패턴 배수 = 기본 패턴 값 × 곱보정 + 합보정`
