# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯머신 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 5 — 자금 배분 시스템 개편 / v0.5.2**

현재 구현된 것:

- 핀테크 / 트레이딩 앱 스타일 UI
- 5×3 세로 릴
- v0.1.3에서 확정한 회전 속도 유지
- 가로 3/4/5, 세로, 대각선, V, 역 V, X 패턴 판정
- 겹쳐 성립하는 패턴 전부 합산
- 15칸 전체 동일 심볼 JACKPOT + 일반 패턴 동시 합산
- NORMAL / RISK 라운드 선택
- NORMAL: 6회전 + 티켓 1
- RISK: 3회전 + 티켓 3
- 마감당 최대 3라운드
- 3라운드 실패 시 GAME OVER
- 금고 정기예치 2~5라운드
- 금고/마감계좌 모두 현재 목표의 5% 단위 입금
- 금고 목표액 50% 예치마다 즉시 티켓 +1
- 금고 중도출금 불가
- 실제로 완료한 라운드만 금고 만기 카운트 감소
- 만기 시 원금+수익 자동 지갑 지급
- Deadline Account 직접 납부
- 마감계좌 납부금 회수 불가
- 마감계좌 100% 달성 시 마감 확정 가능
- 지갑 잔액이 목표 이상이어도 직접 납부하지 않으면 Deadline 미달

## 금고 정기예치

### 기간 / 수익률 — 임시 밸런스

| 잠금 기간 | 만기 수익률 |
| --- | ---: |
| 2 라운드 | +30% |
| 3 라운드 | +45% |
| 4 라운드 | +65% |
| 5 라운드 | +90% |

기간 자체는 더 이상 티켓을 지급하지 않습니다.

### 금고 입금 방식

1. 라운드 시작 전에 2R / 3R / 4R / 5R 중 기간 선택
2. `+5% 예치` 버튼을 눌러 현재 Deadline 목표의 5%씩 지갑에서 금고로 이동
3. 원하는 만큼 반복 예치 가능
4. 다음 라운드를 시작하는 순간 금고가 `LOCKED`
5. 이후 중도출금 불가
6. 실제 라운드를 끝낼 때마다 남은 기간 -1
7. 만기 시 원금 + 수익을 지갑으로 자동 지급

예시: Deadline 목표가 `$200`이면 `+5% 예치` 1회는 `$10`입니다.

### 금고 티켓 규칙

예치를 시작한 시점의 Deadline 목표액을 기준으로 고정합니다.

- 목표의 50%를 예치할 때마다 티켓 +1
- 목표의 100% 누적 예치 → 총 +2T
- 목표의 150% 누적 예치 → 총 +3T
- 기간이 길다고 추가 티켓을 주지 않음

예시: 기준 목표 `$200`

- `$100` 누적 예치 → +1T
- `$200` 누적 예치 → 추가 +1T, 총 +2T
- `$300` 누적 예치 → 추가 +1T, 총 +3T

티켓 기준은 금고 첫 입금 시점의 목표액으로 저장되며, 이후 Deadline 목표가 커져도 해당 예치의 기준은 바뀌지 않습니다.

## Deadline Account

기존의 자동 목표 차감은 제거했습니다.

- 현재 목표액의 5%씩 `+5% 납부`
- 납부액은 지갑에서 빠지고 Deadline Account에 저장
- 납부한 돈은 다시 출금 불가
- 오직 Deadline Account에 들어간 금액만 마감 진행도로 인정
- 100% 납부하면 `마감 확정` 버튼 활성화
- 라운드 종료 시 이미 100% 납부된 상태라면 자동으로 해당 Deadline 완료 처리

예시: 목표 `$80`

- 1회 납부 = `$4`
- 10회 납부 = `$40 / $80`
- 20회 납부 = `$80 / $80`

지갑에 `$500`이 있어도 Deadline Account가 `$60 / $80`이면 미납 상태입니다.

## 조기 마감 보너스

마감계좌를 100% 채운 뒤 `마감 확정`을 누르면 아직 시작하지 않은 라운드마다 티켓 +2를 받습니다.

- Round 1 진행 중 확정 → 이후 Round 2/3 미사용 → +4T
- Round 2 진행 중 확정 → 이후 Round 3 미사용 → +2T
- Round 3 → +0T

라운드 시작 전 이미 마감을 전액 납부한 경우에는 아직 시작하지 않은 현재/이후 라운드도 미사용 라운드로 계산합니다.

## 현재 돈의 역할

### 지갑

- 회전 수익이 들어오는 자유 자금
- 마감계좌 납부에 사용
- 금고 예치에 사용
- 향후 상점 구매에 사용

### 금고

- 고수익 정기예치
- 5% 단위로 자금을 묶음
- 예치 기준 목표의 50%마다 티켓 획득
- 잠긴 자금은 Deadline 납부에 사용할 수 없음

### 마감계좌

- Deadline 생존용 납부 계좌
- 5% 단위 직접 납부
- 납부금 회수 불가
- 100% 채워야 Deadline 통과

## 점수 계산

`심볼 가치 × 심볼 배율 × 패턴 포함 칸 수 × 패턴 기본값 × 패턴 배율 × 전체 배율`

- V = 구성 대각선 2개 + V
- JACKPOT = 성립한 모든 일반 패턴 + JACKPOT 보너스
- 같은 가로 연속 구간에서는 가장 큰 가로 패턴만 계산

## 개발 테스트 버튼

`패턴 테스트`는 검수용입니다.

- 패턴/점수 계산 미리보기
- 지갑 미반영
- 라운드 회전 횟수 미차감
- 티켓 변화 없음
- 금고 만기 카운트 미차감
- 마감계좌 변화 없음

## 아직 구현하지 않은 것

- 상점
- 아이템 효과
- 실제 심볼 등장 확률 가중치
- Error / Wild / Luck 실제 시스템
- 공포/빨간 경고 UI
- 릴 정지 사운드
- 최종 JACKPOT/당첨 연출
- 최종 엔딩 / Endless
