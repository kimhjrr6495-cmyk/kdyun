# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 7 — 첫 20개 아이템 + 실제 효과 / v0.7.1**

현재 핵심 흐름:

1. 라운드 준비
2. 마감 납부 / 금고 / 상점 이용
3. 5×3 릴의 가운데 열 맨 아래 칸 중심에서 `7회 리롤(+1T)` 또는 `3회 리롤(+3T)` 선택
4. **리롤 선택 버튼을 누르는 순간 라운드가 즉시 확정/시작**
5. 동시에 납부 / 금고 / 상점 잠금
6. 선택 UI는 즉시 사라지고 하단 `리롤` 버튼이 등장
7. 선택 클릭 자체는 리롤을 소비하지 않아 `7/7` 또는 `3/3`에서 시작
8. 실제 리롤 소진 후 다음 라운드 준비
9. 3라운드 종료 뒤에는 상점 없이 0라운드 최종 납부 또는 게임 오버 판정

## v0.7.1 라운드 시작 방식

별도의 `시작` 버튼은 없습니다.

- 준비 중에는 하단 시작 버튼을 숨김
- `7회 리롤` 클릭 → 즉시 7회 모드 시작 / 티켓 +1
- `3회 리롤` 클릭 → 즉시 3회 모드 시작 / 티켓 +3
- 선택 클릭은 실제 리롤을 소모하지 않음
- 라운드 시작 후 하단에 `리롤` 버튼 표시
- 선택 취소 단계 없음

따라서 준비 중에는 먼저 납부 / 금고 / 상점을 정리하고 마지막으로 7회/3회 중 하나를 선택합니다.

## 준비 선택 UI 표시 규칙

`7회 / 3회` 선택 UI는 실제로 조작 가능한 라운드 준비 상태에서만 표시합니다.

다음 상태에서는 즉시 숨깁니다.

- 상점이 열려 있을 때
- 마감 목표 완납 후 성공/정산 알림이 열려 있을 때
- 다른 차단 오버레이가 열려 있을 때
- 라운드 정산 중
- 실제 라운드 진행 중
- 0라운드 최종 납부 단계
- GAME OVER / RUN COMPLETE

차단 화면이 끝나고 새로운 라운드 준비 상태가 완전히 만들어진 뒤에만 선택 UI가 다시 나타납니다.

선택 UI 위치는 `reels-shell` 기준 `left: 50% / top: 83.333%`입니다.

## 상점

상점은 **라운드 준비 중이며 아직 7회/3회를 선택하기 전**에만 이용할 수 있습니다.

- 사용 가능 → 검정 배경 + 흰 글씨
- 라운드 시작 / 정산 / 팝업 / 0라운드 → 비활성
- 한 번에 4개 제안
- 실제 20개 아이템 풀에서 중복 없이 4개 선택
- 티켓으로 구매
- 최대 6개 보유
- 새로고침 기본 비용 1T → 2T → 3T → ...
- 같은 준비 구간에서 상점을 닫았다 다시 열어도 제안 / 새로고침 횟수 유지
- 우측 상단 `×`, 배경 클릭, ESC로 닫기
- 상점 아래 보유 아이템 영역에서 판매 가능

현재 판매가는 구매가의 절반을 내림한 값이며 최소 1T입니다.

## Stage 7 아이템 시스템

상점에는 실제 효과가 연결된 첫 20개 아이템이 있습니다. 같은 아이템을 여러 개 보유하면 효과가 중첩됩니다.

기본 점수 공식:

`심볼 가치 × 심볼 배율 × 패턴 칸 수 × 패턴 기본값 × 패턴 배율 × 전체 배율`

아이템은 심볼 가치 / 패턴 배율 / 전체 배율 / 조건부 배율 / 티켓 / 상점 비용을 수정합니다.

| 아이템 | 가격 | 효과 |
| --- | ---: | --- |
| 체리 스티커 | 1T | 체리 패턴 심볼 가치 +1 |
| 코인 광택제 | 1T | 코인 패턴 심볼 가치 +1 |
| 벨 해머 | 2T | 벨 패턴 심볼 가치 +2 |
| 스타 렌즈 | 2T | 스타 패턴 심볼 가치 +2 |
| 다이아 커터 | 3T | 다이아 패턴 심볼 가치 +3 |
| 크라운 인장 | 3T | 크라운 패턴 심볼 가치 +3 |
| 세븐 스탬프 | 4T | 세븐 패턴 심볼 가치 +4 |

### 패턴 강화 6개

| 아이템 | 가격 | 효과 |
| --- | ---: | --- |
| 가로 배선 | 2T | 가로 3/4/5 점수 ×1.20 |

| 사선 자 | 2T | 대각선 점수 ×1.30 |
