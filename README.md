# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯머신 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 5 — 금고 시스템 개편 / v0.5.1**

현재 구현된 것:

- 핀테크 / 트레이딩 앱 스타일 UI
- 5×3 세로 릴
- v0.1.3에서 확정한 회전 속도 유지
- 가로 3/4/5, 세로, 대각선, V, 역 V, X 패턴 판정
- 겹쳐 성립하는 패턴 전부 합산
- 15칸 전체 동일 심볼 JACKPOT + 일반 패턴 동시 합산
- NORMAL / RISK 라운드 선택
- NORMAL: 6회전 + 티켓 1
- RISK: 3회전 + 티켓 3
- 마감당 최대 3라운드
- 3라운드 실패 시 GAME OVER
- 금고 정기예치 2~5라운드
- 예치 기간이 길수록 높은 만기 수익과 티켓 보너스
- 예치 중도출금 불가
- 실제로 완료한 라운드만 금고 만기 카운트 감소
- 만기 시 원금+수익 자동 지갑 지급 및 티켓 지급
- 한 번에 금고 예치 1건만 가능
- 잠긴 금고 자금은 현재 Deadline 목표 판정/정산에서 제외

## 금고 정기예치 — 임시 밸런스

| 잠금 기간 | 만기 수익률 | 만기 티켓 |
| --- | ---: | ---: |
| 2 라운드 | +30% | +0T |
| 3 라운드 | +45% | +1T |
| 4 라운드 | +65% | +2T |
| 5 라운드 | +90% | +3T |

현재 수치는 테스트용이며 플레이 감각 확인 후 조정할 예정입니다.

### 예치 방식

라운드 시작 전 금고에서 기간을 먼저 선택합니다.

- 2R / 3R / 4R / 5R 중 선택
- 지갑의 25% / 50% / 전액 중 선택해 예치
- 예치 직후 돈은 지갑에서 빠지고 금고에 잠김
- 중도출금 불가
- 조기상환 등으로 라운드를 건너뛰어도 금고 카운트는 줄지 않음
- 실제 플레이로 한 라운드를 끝낼 때만 남은 기간 -1

예시:

`$100을 4R 예치 → 4개 라운드 완료 → $165 + 2T 지급`

## 현재 지갑 / 금고 역할

### 지갑

- 자유롭게 사용할 수 있는 유동 자금
- 회전 보상이 들어오는 곳
- 현재 Deadline 자동 정산에 사용
- 금고 예치 원금의 출처
- 자체 이자 없음

### 금고

- 고수익 장기 투자용
- 예치 기간 동안 완전히 잠김
- 잠긴 돈은 Deadline 목표에 포함되지 않음
- 만기에만 원금과 수익이 지갑으로 돌아옴

따라서 금고에 너무 많은 돈을 넣으면 현재 Deadline을 못 갚아 GAME OVER가 될 수 있습니다.

## 현재 마감 정산 규칙

**v0.5.1에서는 금고만 먼저 개편했기 때문에 마감 납부는 아직 기존 자동 방식입니다.**

- 라운드 종료 시 지갑이 목표 이상이면 자동 정산
- 잠긴 금고 예치금은 정산에 사용할 수 없음
- 조기상환도 지갑만 기준으로 활성화
- 사용자 직접 입금형 `DEADLINE ACCOUNT` 시스템은 다음 수정 후보

## 점수 계산

`심볼 가치 × 심볼 배율 × 패턴 포함 칸 수 × 패턴 기본값 × 패턴 배율 × 전체 배율`

- V = 구성 대각선 2개 + V
- JACKPOT = 성립한 모든 일반 패턴 + JACKPOT 보너스
- 같은 가로 연속 구간에서는 가장 큰 가로 패턴만 계산

## 개발 테스트 버튼

`패턴 테스트`는 검수용입니다.

- 패턴/점수 계산 미리보기
- 지갑 미반영
- 라운드 회전 횟수 미차감
- 티켓 변화 없음
- 금고 만기 카운트 미차감

## 아직 구현하지 않은 것

- 사용자 직접 마감 입금 계좌
- 상점
- 아이템 효과
- 실제 심볼 등장 확률 가중치
- Error / Wild / Luck 실제 시스템
- 공포/경고 UI
- 릴 정지 사운드
- 최종 JACKPOT/당첨 연출
- 최종 엔딩 / Endless
