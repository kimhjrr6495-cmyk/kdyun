# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 7 — 첫 20개 아이템 + 실제 효과 + 순차 당첨 연출 + 실시간 가치표 / v0.7.3**

현재 핵심 흐름:

1. 라운드 준비
2. 마감 납부 / 금고 / 상점 이용
3. `7회 리롤(+1T)` 또는 `3회 리롤(+3T)` 선택
4. 선택 즉시 라운드 시작
5. 납부 / 금고 / 상점 잠금
6. 하단 `리롤` 버튼으로 실제 리롤 진행
7. 여러 패턴 당첨 시 가로 → 세로 → 대각선 → V/역V → X → 잭팟 순서로 정산
8. 3라운드 종료 뒤 0라운드 최종 납부 또는 게임 오버 판정

## v0.7.3 실시간 심볼 가격표

오른쪽 `심볼 가격` 표는 이제 정적인 기본값 표가 아니라 현재 빌드 상태를 보여줍니다.

표시 순서:

`등장확률 | 심볼 | 현재 가치 | 변화식`

예시:

```text
14.3%  다이아  $9 (+3)
14.3%  세븐    $24 (×2)
14.3%  체리    $6 (×2 +2)
```

계산 규칙은 다음과 같이 통일합니다.

`현재 심볼 가치 = 기본 심볼 가치 × 곱보정 + 합보정`

현재 Stage 7 아이템은 `+VALUE` 효과를 사용하고 있습니다. v0.7.3부터 추후 `symbol_value_mult` 타입이 추가되면 실제 점수와 오른쪽 표가 동시에 `×` 보정을 반영하도록 준비했습니다.

### 심볼 등장확률

현재 `randomSymbol()`은 7개 심볼을 **균등 랜덤**으로 선택합니다.

따라서 현재 실제 등장확률은 모든 심볼이:

`1 / 7 ≈ 14.3%`

입니다.

아직 실제 심볼 가중치 시스템은 구현하지 않았습니다. 따라서 현재 화면에서 체리/세븐 등의 확률을 임의로 다르게 표시하지 않습니다.

## 가치 상승 색상

심볼 가치 또는 패턴 배수가 기본값보다 올라가면 현재 숫자 색이 단계적으로 더 희귀하게 보입니다.

- 기본값: 기본 텍스트색
- 소폭 강화: 그린 계열
- 중간 강화: 블루/바이올렛 계열
- 큰 강화: 골드 계열
- 매우 큰 강화: 마젠타 계열

색상은 실제 계산값 대비 기본값의 상승 비율을 기준으로 자동 결정합니다.

## v0.7.3 실시간 패턴 배수표

`패턴 배수`도 현재 적용값을 표시합니다.

기본값:

- 가로 3 ×1
- 가로 4 ×2
- 가로 5 ×4
- 세로 3 ×1.5
- 대각선 ×2
- V ×6
- 역 V ×6
- X ×8
- 잭팟 ×12

예를 들어 `가로 배선(×1.20)`을 보유하면:

```text
가로 3  ×1.2 (×1.2)
가로 4  ×2.4 (×1.2)
가로 5  ×4.8 (×1.2)
```

처럼 표시됩니다.

계산 규칙:

`현재 패턴 배수 = 기본 패턴 값 × 곱보정 + 합보정`

현재 아이템의 `pattern_mult`는 실제 점수와 이 표에 동일하게 반영됩니다. 추후 `pattern_add` 타입도 실제 점수와 표에서 같은 규칙으로 처리할 수 있게 준비했습니다.

## 순차 당첨 연출

한 번의 리롤에서 여러 종류의 패턴이 동시에 성립하면 다음 순서로 그룹별 정산합니다.

1. 가로 — H3 / H4 / H5
2. 세로 — V3
3. 대각선 — DIAG
4. V 패턴 — V / 역 V
5. X
6. 잭팟

같은 종류의 패턴 여러 개는 한 그룹으로 같이 강조하고, 그룹별 지급액을 누적한 뒤 마지막에 전체 당첨 결과를 표시합니다.

## Stage 7 아이템 시스템

상점에는 실제 효과가 연결된 첫 20개 아이템이 있습니다. 같은 아이템을 여러 개 보유하면 효과가 중첩됩니다.

기본 점수 공식:

`심볼 가치 × 심볼 배율 × 패턴 칸 수 × 패턴 기본값 × 패턴 배율 × 전체 배율`

현재 주요 아이템 예시:

- 체리 스티커 — 체리 가치 +1
- 코인 광택제 — 코인 가치 +1
- 벨 해머 — 벨 가치 +2
- 스타 렌즈 — 스타 가치 +2
- 다이아 커터 — 다이아 가치 +3
- 크라운 인장 — 크라운 가치 +3
- 세븐 스탬프 — 세븐 가치 +4
- 가로 배선 — 가로 3/4/5 ×1.20
- 세로 배선 — 세로 3 ×1.25
- 사선 자 — 대각선 ×1.30
- V 프레임 — V/역V ×1.30
- X 브릿지 — X ×1.35
- 잭팟 퓨즈 — 잭팟 ×1.50
- 시장 증폭기 — 전체 ×1.08
- 프리미엄 터미널 — 전체 ×1.15
- 개장 알림 — 첫 리롤 ×1.25
- 마감 벨 — 마지막 리롤 ×1.35
- 분산 포트폴리오 — 서로 다른 심볼 6종 이상이면 ×1.25
- 티켓 펀치 — 라운드 시작 티켓 +1
- 새로고침 쿠폰 — 상점 새로고침 비용 -1T, 최소 1T
