# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯머신 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 6 — 라운드 준비 허브 / 수동 상점 / 컴팩트 아이템 트레이 / v0.6.1**

현재 구현된 것:

- 5×3 세로 릴과 패턴/점수 시스템
- **7회 리롤(+1T) / 3회 리롤(+3T)** 선택
- 마감당 플레이 라운드 3개 + 최종 납부용 0라운드
- 라운드 전 마감 납부 / 금고 설정
- 마감 확정 버튼 없이 목표 완납 시 자동 진행
- 금고 2라운드 / 4라운드 복리 상품
- 납부 게이지의 확정분 / 이번 준비분 색상 구분
- 0.6초 재화 카운트업 + 초록색 `+금액` 플로팅
- 하단 버튼 하나를 준비 중에는 `시작`, 진행 중에는 `리롤`로 사용
- 라운드 준비 화면 오른쪽의 수동 `상점` 버튼
- 상점 4개 제안 / 티켓 구매 / 제안 새로고침
- 최대 보유 아이템 6개
- 오른쪽 아래 컴팩트 아이템 트레이
- 아이템 마우스 오버 설명 / 클릭 판매 확인

## 라운드 흐름

1. 라운드가 끝나면 별도 선택 팝업 없이 **라운드 준비 화면**으로 이동
2. 준비 화면에서는 마감 계좌 / 금고 / 상점을 사용할 수 있음
3. 슬롯 머신은 회색 잠금 상태로 유지
4. 슬롯 위에서 `7회 리롤(+1T)` 또는 `3회 리롤(+3T)` 선택
5. 선택한 카드의 테두리가 강조되고 마감 계좌 / 금고가 잠김
6. 같은 카드를 다시 누르면 선택 취소 → 마감 계좌 / 금고가 다시 열림
7. 선택이 있는 동안 하단 `시작` 버튼 활성화
8. `시작` 클릭 시 선택 확정 + 해당 티켓 지급
9. 슬롯 잠금 해제, 같은 버튼이 `리롤`로 변경
10. 실제 리롤 횟수를 모두 사용하면 다음 라운드 준비로 이동
11. 3라운드 종료 뒤에는 상점 없이 즉시 0라운드/게임오버 판정

즉 현재 핵심 흐름은 **준비 → 납부/금고/상점 → 7회/3회 선택 → 시작 → 리롤 → 다음 준비**입니다.

## 7회 / 3회 선택

라운드 방식 선택 팝업은 제거했습니다.

슬롯 머신 위의 준비 바에서 선택합니다.

- `7회 리롤` → 실제 리롤 7회 / 시작 시 티켓 +1
- `3회 리롤` → 실제 리롤 3회 / 시작 시 티켓 +3

아무것도 선택하지 않으면 `시작` 버튼은 비활성입니다.

리롤 횟수를 선택하면:

- 선택 카드 테두리 강조
- 마감 계좌 잠금
- 금고 잠금
- `시작` 버튼 활성

선택한 카드를 다시 누르면 취소되며 납부/금고를 다시 사용할 수 있습니다.
티켓은 선택 순간이 아니라 실제 `시작`을 누르는 순간 지급됩니다.

## 시작 / 리롤 단일 버튼

별도의 중앙 시작 버튼은 없습니다.

하단 같은 버튼이 상태에 따라 역할만 바뀝니다.

- 준비 + 선택 없음: `시작` 비활성
- 준비 + 7회/3회 선택: `시작` 활성
- 실제 라운드 진행: `리롤`
- 상점 / 0라운드 / 정산: 비활성

`시작` 클릭은 리롤 횟수를 소비하지 않습니다.

## 마감 계좌

- 현재 마감 목표의 5% 단위로 직접 납부
- 버튼에는 `납부`만 표시
- `1회 납부금` 문구 없음
- 목표 완납 즉시 자동 정산
- 라운드 준비 중 리롤 횟수를 고르기 전까지 조작 가능
- 7회/3회를 고르면 잠김
- 선택 취소 시 다시 열림
- 0라운드 최종 납부에서는 다시 납부 가능

### 납부 게이지

- 이미 확정된 납부액: 검정/회색
- 현재 준비 중 새로 납부한 금액: 빨간색
- `시작` 클릭 시 빨간 구간이 확정색으로 전환
- 0라운드에서는 마지막 신규 납부 구간이 빨간색으로 유지

## 0라운드 — 최종 납부

3라운드 종료 후:

- `현재 납부액 + 지갑 < 목표` → 게임 오버
- `현재 납부액 + 지갑 >= 목표` → **0라운드 · 최종 납부**

0라운드에서는 추가 리롤 / 금고 예치 / 상점이 없고 마감 납부만 가능합니다.
**3라운드 종료 후 상점은 열리지 않습니다.**

## 금고

리롤 횟수를 선택하기 전 준비 상태에서 왼쪽 금고를 사용합니다.

- 2라운드 / 4라운드
- 현재 마감 목표의 5% 단위 반복 예치
- 7회/3회 선택 시 조작 잠금
- 선택 취소 시 다시 조작 가능
- 실제 `시작` 클릭 순간 예치 확정/잠금
- 실제 플레이 라운드 종료 때만 기간 감소
- 잠긴 동안 추가 예치 / 중도출금 불가

### 2라운드 상품

| 완료 라운드 | 이율 | 티켓 |
| --- | ---: | ---: |
| 1 | +15% | - |
| 2 | +15% | +1 |

### 4라운드 상품

| 완료 라운드 | 이율 | 티켓 |
| --- | ---: | ---: |
| 1 | +15% | - |
| 2 | +15% | +1 |
| 3 | +25% | - |
| 4 | +25% | +1 |

이자는 현재 금고 잔액 기준 복리이며 소수점은 버립니다.

예: `$50` 4라운드 예치 → `50 → 57 → 65 → 81 → 101`

## Stage 6 상점

상점은 더 이상 라운드 종료 때 자동으로 열리지 않습니다.

라운드 준비 화면 오른쪽의 **`상점` 버튼**으로 직접 들어갑니다.

- 라운드 시작 전만 이용 가능
- 0라운드에서는 이용 불가
- 한 번에 아이템 4개 제안
- 티켓으로 구매
- 최대 6개 보유
- 제안 새로고침 비용 1T → 2T → 3T → ...
- 같은 라운드에서 상점을 닫았다 다시 열어도 제안/새로고침 비용은 유지
- 상점을 닫으면 그대로 같은 라운드 준비 화면으로 복귀

현재 아이템들은 Stage 7 효과 구현 전 임시 껍데기입니다.

## 오른쪽 아래 아이템 트레이

기존 오른쪽 전체 높이 아이템 서랍 대신 작은 고정 트레이를 사용합니다.

- 우측 하단에 6칸 표시
- 보유 개수 `0 / 6` 표시
- 아이템에 마우스를 올리면 이름 + 짧은 효과 설명 툴팁
- 아이템 클릭 시 판매 확인 팝업
- 판매는 라운드 준비 또는 상점 이용 중에만 가능
- 현재 임시 판매가는 구매가의 절반 기준, 최소 1T

상점 화면은 구매 중심으로 단순화했고 보유/판매는 오른쪽 트레이에서 담당합니다.
