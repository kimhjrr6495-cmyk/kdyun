# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯머신 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 1 — 5×3 릴 회전 감각**

현재 구현된 것:

- 핀테크 / 트레이딩 앱 스타일 UI
- 왼쪽 마감·지갑·금고 정보 패널
- 중앙 5×3 슬롯
- 7종 기본 심볼의 임시 문자 표현
- 5개의 세로 릴 구조
- 회전 버튼
- Space 키 회전
- 랜덤 심볼 결과 생성
- 1~5열 순차 정지
- ease-out 기반 부드러운 감속
- 중복 회전 입력 방지
- 오른쪽 마우스 오버형 아이템 패널 미리보기
- 반응형 기본 레이아웃

## Stage 1에서 일부러 구현하지 않은 것

- 패턴 판정
- 점수 계산
- 마감 / 라운드 실제 로직
- 상점
- 아이템 효과
- 당첨 칸 강조
- 숫자 카운트업
- 릴 정지 사운드
- 당첨 / 위험 이펙트

이 기능들은 후속 단계에서 순서대로 연결합니다.

## 현재 검수 포인트

Stage 1에서는 릴의 움직임만 평가합니다.

- 전체 회전 시간이 적당한가
- 5개 릴의 정지 간격이 자연스러운가
- 너무 빠르거나 너무 느리지 않은가
- 세로 스크롤이 슬롯보다 금융 티커에 가까운 느낌인가
- 심볼 크기와 5×3 보드 비율이 적당한가

## 파일 구조

- `index.html` — 메인 화면 구조
- `style.css` — 전체 UI 스타일
- `data.js` — 심볼 / 릴 파라미터 등 공용 데이터
- `game.js` — 현재 릴 회전 로직
- `effects.js` — 후속 시각 / 사운드 이펙트 전용
