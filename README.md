- 마감당 플레이 라운드 3개 + 최종 납부용 0라운드
- 라운드 전 마감 납부 / 금고 설정

- 하단 버튼 하나를 준비 중에는 `시작`, 진행 중에는 `리롤`로 사용
- 하단 우측의 수동 `상점` 버튼

- 지갑 한 줄에 돈과 티켓 동시 표시

## 라운드 흐름

1. 라운드가 끝나면 별도 선택 팝업 없이 **라운드 준비 화면**으로 이동
2. 준비 화면에서는 마감 계좌 / 금고 / 상점을 사용할 수 있음
3. 슬롯 머신은 회색 잠금 상태로 유지
4. 슬롯 위에서 `7회 리롤(+1T)` 또는 `3회 리롤(+3T)` 선택
5. 선택한 카드 테두리가 강조되고 마감 계좌 / 금고가 잠김
6. 같은 카드를 다시 누르면 선택 취소 → 마감 계좌 / 금고 다시 활성
7. 선택이 있는 동안 하단 `시작` 버튼 활성
8. `시작` 클릭 시 선택 확정 + 해당 티켓 지급
9. 슬롯 잠금 해제, 같은 버튼이 `리롤`로 변경
10. 실제 리롤 횟수를 모두 사용하면 다음 라운드 준비로 이동
11. 3라운드 종료 뒤에는 상점 없이 즉시 0라운드/게임오버 판정

즉 현재 핵심 흐름은 **준비 → 납부/금고/상점 → 7회/3회 선택 → 시작 → 리롤 → 다음 준비**입니다.

## 지갑 / 티켓

상단 상태바의 별도 티켓 칩은 제거했습니다.

지갑 카드 한 줄에서 돈과 티켓을 함께 표시합니다.

```text
$ 1,250                         T 7
```

돈은 왼쪽, 티켓은 오른쪽에 배치됩니다.

## 7회 / 3회 선택

라운드 방식 선택 팝업은 제거했습니다.

슬롯 머신 위 준비 바에서 선택합니다.

- `7회 리롤` → 실제 리롤 7회 / 시작 시 티켓 +1
- `3회 리롤` → 실제 리롤 3회 / 시작 시 티켓 +3

아무것도 선택하지 않으면 `시작` 버튼은 비활성입니다.

리롤 횟수를 선택하면:

- 선택 카드 테두리 강조
- 마감 계좌 잠금
- 금고 잠금
- `시작` 버튼 활성

선택한 카드를 다시 누르면 취소되며 납부/금고를 다시 사용할 수 있습니다.
티켓은 선택 순간이 아니라 실제 `시작`을 누르는 순간 지급됩니다.

## 시작 / 리롤 단일 버튼

별도의 중앙 시작 버튼은 없습니다.

하단 같은 버튼이 상태에 따라 역할만 바뀝니다.

- 준비 + 선택 없음: `시작` 비활성
- 준비 + 7회/3회 선택: `시작` 활성
- 실제 라운드 진행: `리롤`
- 상점 / 0라운드 / 정산: 비활성

`시작` 클릭은 리롤 횟수를 소비하지 않습니다.

## 마감 계좌

- 현재 마감 목표의 5% 단위로 직접 납부
- 목표 완납 즉시 자동 정산
- 라운드 준비 중 리롤 횟수를 고르기 전까지 조작 가능
- 7회/3회를 고르면 잠김
- 선택 취소 시 다시 열림
- 0라운드 최종 납부에서는 다시 납부 가능

### 납부 게이지

- 이미 확정된 납부액: 검정/회색
- 현재 준비 중 새로 납부한 금액: 빨간색
- `시작` 클릭 시 빨간 구간이 확정색으로 전환
- 0라운드에서는 마지막 신규 납부 구간이 빨간색으로 유지

## 0라운드 — 최종 납부

3라운드 종료 후:

- `현재 납부액 + 지갑 < 목표` → 게임 오버
- `현재 납부액 + 지갑 >= 목표` → **0라운드 · 최종 납부**

0라운드에서는 추가 리롤 / 금고 예치 / 상점이 없고 마감 납부만 가능합니다.
**3라운드 종료 후 상점은 열리지 않습니다.**

## 금고

리롤 횟수를 선택하기 전 준비 상태에서 왼쪽 금고를 사용합니다.

- 2라운드 / 4라운드
- 현재 마감 목표의 5% 단위 반복 예치
- 7회/3회 선택 시 조작 잠금
- 선택 취소 시 다시 조작 가능
- 실제 `시작` 클릭 순간 예치 확정/잠금
- 실제 플레이 라운드 종료 때만 기간 감소
- 잠긴 동안 추가 예치 / 중도출금 불가

### 2라운드 상품

| 완료 라운드 | 이율 | 티켓 |
| --- | ---: | ---: |
| 1 | +15% | - |
| 2 | +15% | +1 |

### 4라운드 상품

| 완료 라운드 | 이율 | 티켓 |
| --- | ---: | ---: |
| 1 | +15% | - |
| 2 | +15% | +1 |
| 3 | +25% | - |
| 4 | +25% | +1 |

이자는 현재 금고 잔액 기준 복리이며 소수점은 버립니다.

예: `$50` 4라운드 예치 → `50 → 57 → 65 → 81 → 101`

## Stage 6 상점 — v0.6.2 UX

상점은 더 이상 라운드 종료 때 자동으로 열리지 않습니다.

하단 액션바 오른쪽의 **`상점` 버튼**으로 직접 들어갑니다.
기존 `출금하기` 버튼은 제거했습니다.

### 이용 조건

- 라운드 시작 전만 이용 가능
- 실제 리롤 진행 중 이용 불가
- 0라운드 이용 불가
- 상점을 닫으면 그대로 같은 라운드 준비 화면으로 복귀

### 상점 모달

상점은 게임 진행 오버레이와 분리된 전용 모달 느낌으로 표시됩니다.

- `마감 N`, `라운드 N` 같은 진행 정보 표시 없음
- 상단에는 `상점`, 현재 티켓, 보유 개수만 표시
- 우측 상단 작은 `×` 버튼으로 닫기
- 상점 카드 바깥의 어두운 배경 클릭으로 닫기
- `ESC` 키로 닫기

### 아이템 제안

- 한 번에 아이템 4개 제안
- 이름 / 아이콘 영역 / 짧은 효과 / 가격을 분리해 표시
- 티켓으로 구매
- 보유 아이템이 6개면 추가 구매 불가

### 제안 새로고침

새로고침은 메인 액션보다 작은 보조 버튼으로 표시됩니다.

- 첫 새로고침: 1T
- 두 번째: 2T
- 세 번째: 3T
- 이후 계속 +1T
- 같은 라운드에서 상점을 닫았다 다시 열어도 제안/비용 유지

### 상점 내 보유 아이템

구매 제안 바로 아래에 큰 **보유 아이템 0/6** 영역이 표시됩니다.

- 6칸 전체 확인 가능
- 구매 즉시 아래 보유 영역에 반영
- 보유 아이템 클릭 시 판매 모달 표시

## 아이템 트레이 / 판매

평상시에는 우측 하단 작은 아이템 트레이를 유지합니다.

- 6칸 표시
- 보유 개수 표시
- 마우스를 올리면 이름 + 짧은 효과 툴팁
- 아이템 클릭 시 판매 확인

판매 확인 UI는 v0.6.2부터 작은 팝오버 대신 중앙의 큰 모달로 표시합니다.

- 아이템 이름
- 효과 설명
- 구매가
- 판매가
- 큰 판매 버튼
- 취소 버튼

현재 임시 판매가는 구매가의 절반 기준, 최소 1T입니다.

현재 아이템들은 Stage 7 효과 구현 전 임시 껍데기입니다.
