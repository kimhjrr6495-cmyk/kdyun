# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 7 — 첫 20개 아이템 + 실제 효과 / v0.7.0**

현재 핵심 흐름:

1. 라운드 준비
2. 마감 납부 / 금고 / 상점 이용
3. 5×3 릴의 가운데 열 맨 아래 칸 중심에서 `7회 리롤(+1T)` 또는 `3회 리롤(+3T)` 선택
4. 리롤 횟수를 선택하면 **납부 / 금고 / 상점이 동시에 잠김**
5. 같은 선택을 다시 누르면 취소되고 납부 / 금고 / 상점이 다시 활성화
6. `시작` 버튼으로 선택 확정
7. 시작 후 같은 버튼이 `리롤`로 변경
8. 실제 리롤 소진 후 다음 라운드 준비
9. 3라운드 종료 뒤에는 상점 없이 0라운드 최종 납부 또는 게임 오버 판정

## 라운드 준비 잠금 규칙

리롤 횟수를 고르기 전에는 다음 기능을 사용할 수 있습니다.

- 마감 납부
- 금고 설정 / 예치
- 상점

`7회` 또는 `3회`를 선택한 순간:

- 마감 납부 잠금
- 금고 잠금
- **상점 잠금**
- 시작 버튼 활성

같은 리롤 선택 버튼을 다시 누르면 선택이 취소되며 세 기능이 모두 다시 열립니다.
상점 버튼은 사용 가능할 때 검정 배경 + 흰 글씨, 선택 후 잠겼을 때 흰 배경 + 흐린 글씨로 표시됩니다.

## 7회 / 3회 선택

- `7회 리롤` → 실제 리롤 7회 / 시작 시 티켓 +1
- `3회 리롤` → 실제 리롤 3회 / 시작 시 티켓 +3
- `시작` 클릭 자체는 리롤을 소비하지 않음
- 선택 UI는 `reels-shell` 기준 `left: 50% / top: 83.333%`

## Stage 7 아이템 시스템

상점의 임시 껍데기 아이템을 제거하고 실제 20개 아이템 데이터를 연결했습니다.
최대 6개까지 보유할 수 있고 같은 아이템을 여러 개 보유하면 효과가 중첩됩니다.

점수 공식 자체는 유지합니다.

`심볼 가치 × 심볼 배율 × 패턴 칸 수 × 패턴 기본값 × 패턴 배율 × 전체 배율`

Stage 7 아이템은 이 공식의 `심볼 가치`, `패턴 배율`, `전체 배율`을 수정합니다.
적용된 아이템은 점수 상세 내역에 `아이템 적용`으로 표시됩니다.

### 심볼 강화 7개

| 아이템 | 가격 | 효과 |
| --- | ---: | --- |
| 체리 스티커 | 1T | 체리 패턴 심볼 가치 +1 |
| 코인 광택제 | 1T | 코인 패턴 심볼 가치 +1 |
| 벨 해머 | 2T | 벨 패턴 심볼 가치 +2 |
| 스타 렌즈 | 2T | 스타 패턴 심볼 가치 +2 |
| 다이아 커터 | 3T | 다이아 패턴 심볼 가치 +3 |
| 크라운 인장 | 3T | 크라운 패턴 심볼 가치 +3 |
| 세븐 스탬프 | 4T | 세븐 패턴 심볼 가치 +4 |

### 패턴 강화 6개

| 아이템 | 가격 | 효과 |
| --- | ---: | --- |
| 가로 배선 | 2T | 가로 3/4/5 점수 ×1.20 |
| 세로 배선 | 2T | 세로 3 점수 ×1.25 |
| 사선 자 | 2T | 대각선 점수 ×1.30 |
| V 프레임 | 3T | V / 역 V 점수 ×1.30 |
| X 브릿지 | 3T | X 점수 ×1.35 |
| 잭팟 퓨즈 | 5T | 잭팟 점수 ×1.50 |

### 전체 / 조건부 강화 5개

| 아이템 | 가격 | 효과 |
| --- | ---: | --- |
| 시장 증폭기 | 3T | 모든 패턴 점수 ×1.08 |
| 프리미엄 터미널 | 5T | 모든 패턴 점수 ×1.15 |
| 개장 알림 | 2T | 라운드 첫 리롤 점수 ×1.25 |
| 마감 벨 | 3T | 라운드 마지막 리롤 점수 ×1.35 |
| 분산 포트폴리오 | 3T | 서로 다른 심볼 6종 이상이면 점수 ×1.25 |

### 경제 효과 2개

| 아이템 | 가격 | 효과 |
| --- | ---: | --- |
| 티켓 펀치 | 4T | 라운드 시작 시 선택 보상 티켓 +1 |
| 새로고침 쿠폰 | 3T | 상점 새로고침 비용 -1T, 최소 1T |

## 상점

- 라운드 준비 중 + 리롤 횟수 선택 전만 이용 가능
- 한 번에 4개 제안
- 실제 20개 아이템 풀에서 중복 없이 4개 선택
- 티켓으로 구매
- 최대 6개 보유
- 새로고침 기본 비용 1T → 2T → 3T → ...
- 새로고침 쿠폰은 현재 비용에서 1T씩 할인, 최소 1T
- 같은 준비 구간에서 상점을 닫았다 다시 열어도 제안 / 새로고침 횟수 유지
- 우측 상단 `×`, 배경 클릭, ESC로 닫기
- 상점 아래 큰 보유 아이템 영역에서 판매 가능

현재 판매가는 구매가의 절반을 내림한 값이며 최소 1T입니다.

## 마감 계좌 / 금고

- 현재 마감 목표의 5% 단위로 직접 납부
- 목표 완납 시 자동 정산
- 리롤 선택 전 조작 가능
- 리롤 선택 시 잠금
- 선택 취소 시 다시 활성
- 금고는 실제 플레이 라운드 종료 때만 기간 감소

금고 상품:

- 2라운드: +15% / +15%, 만기 티켓 +1
- 4라운드: +15% / +15% / +25% / +25%, 2·4라운드 티켓 +1
