## v0.9.4 — WILD / ERROR

### 기본 심볼 확률

WILD와 ERROR를 포함해 기본 확률 합계는 100%입니다.

| 심볼 | 기본 가치 | 기본 확률 |
| --- | ---: | ---: |
| 🍒 체리 | $2 | 21% |
| 🪙 코인 | $2 | 21% |
| 🔔 벨 | $3 | 17% |
| ⭐ 스타 | $4 | 13% |
| 💎 다이아 | $6 | 9% |
| 👑 크라운 | $8 | 7% |
| 7️⃣ 세븐 | $12 | 5% |
| 🃏 WILD | 특수 | 3% |
| ⚠️ ERROR | 오류 | 4% |

Luck이 올라가면 💎 / 👑 / 7️⃣과 WILD의 가중치가 상승하고 ERROR 가중치는 감소합니다.

`조커 카드`, `오버클럭`, `카오스 칩` 등은 WILD / ERROR 가중치를 별도로 바꿀 수 있으므로 오른쪽 확률표는 실제 현재 확률을 실시간 표시합니다.

### 🃏 WILD

WILD는 별도의 일반 점수 심볼이 아니라 패턴을 완성할 때 필요한 정상 심볼을 대신합니다.

예:

```text
🍒 🍒 🃏 🍒 🍒  →  체리 가로 5
```

지원 패턴:

- H3 / H4 / H5
- V3
- DIAG
- V / INV_V
- X
- JACKPOT

JACKPOT은 밸런스를 위해 WILD를 최대 1칸까지만 허용합니다.
모든 칸이 WILD인 패턴은 정상 심볼을 결정할 수 없으므로 당첨으로 인정하지 않습니다.

WILD가 포함된 패턴은 실제 대체 대상 심볼의 기본 가치와 기존 아이템 강화를 사용해 계산합니다.

### ⚠️ ERROR

ERROR는 기본적으로 어떤 정상 패턴에도 참여하지 않는 방해 심볼입니다.

릴 정착 뒤 일반 패턴을 찾기 전에 ERROR 전용 처리를 먼저 실행합니다.

기본 처리 순서:

1. 오류 수집기 저장
2. 디버거 변환
3. 백업 파일 복원
4. 불안정한 조커 ERROR→WILD 판정
5. ERROR 2개 이상이면 ERROR EVENT
6. 커널 패닉 / 글리치 라우터 / 오류 증폭기 처리
7. 최종 보드에서 WILD 포함 패턴 판정

ERROR EVENT의 기본 결과는 오류 1칸 복구 / 소액 현금 보상 / 티켓 +1 중 하나입니다.

### v0.9.4 신규 아이템 12개

기존 64개에 12개를 추가해 **총 76개 아이템**을 사용합니다.
같은 아이템 중복 보유는 허용하지 않습니다.

| LEGENDARY | 👑 왕의 조커 | WILD가 💎·👑·7️⃣ 대체 시 ×1.50 |
| RARE | 🧲 오류 수집기 | ERROR마다 $3 저장, 다음 당첨에 지급 |
| RARE | ⚠️ 오버클럭 | ERROR +3%p, 모든 지급 ×1.20 |
| COMMON | 🔧 디버거 | 매 리롤 첫 ERROR 정상화 |

## 안전장치

- JACKPOT WILD 최대 1칸
- 모든 칸 WILD 패턴 불가
- ERROR는 기본 패턴에 직접 참여하지 않음
- 한 리롤 ERROR 변환 처리량 제한
- Stage 8 트리거 최대 깊이 4
- 한 원본 패턴당 트리거 최대 12회
- Stage 9 패턴 재발동 최대 6회
- 동일 아이템 중복 보유 불가
