# DEADLINE

CloverPit 계열의 빌드 구성 재미를 참고해 확장 중인 2D 5×3 슬롯 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 9 COMPLETE — Luck / Modifier / Retrigger / WILD / ERROR / Economy / SHINY / UI Polish v0.9.9**

현재 핵심 흐름:

1. 라운드 준비
2. 마감 계좌 납부 / 상점 이용
3. 마감 3부터 금고 이용 가능
4. `7회 리롤` 또는 `3회 리롤` 선택
5. 선택 즉시 라운드 시작
6. 리롤 수익은 즉시 지갑에 들어가지 않고 `이번 라운드 수익`에 누적
7. Luck / WILD / ERROR / Modifier / Trigger / Retrigger 정산
8. 라운드 종료 시 누적된 라운드 수익을 지갑으로 한 번에 이동
9. 실제 라운드 종료 시 마감 계좌 잔액에 기본 10% 이자 적용
10. 3라운드 종료 뒤 부족하면 0라운드 최종 납부

## v0.9.9 — Stage 9 최종 UI 폴리시 / 라운드 임시지갑

### ✨ SHINY 상점 카드 재배치

SHINY가 붙어도 일반 카드와 카드 크기가 달라지지 않습니다.

상점 카드 구조:

```text
등급                         ✨ SHINY

이모지
아이템 이름                  부가 효과
기본 효과 설명               Trait 이름 / 설명

🎟️ 가격
```

- 일반 / SHINY 모두 데스크톱 기준 202px 고정 높이
- 왼쪽: 이모지 / 이름 / 기본 효과
- 오른쪽: SHINY 부가 효과
- SHINY가 없는 카드도 동일한 그리드 공간을 사용해 레이아웃 이동 방지
- 기존 등급 네온과 SHINY 홀로그램 표현 유지

### 🎟️ 티켓 표기 통일

플레이어에게 보이는 티켓 재화 표기를 기존 `T` 중심에서 `🎟️` 아이콘 중심으로 변경했습니다.

예:

```text
🎟️ 10
🎟️ +3
판매 🎟️ 1
```

내부 변수와 아이템 로직은 기존 `tickets` 구조를 그대로 사용합니다.

### 마감 계좌 UI 단순화

왼쪽 마감 계좌는 필요한 정보만 남깁니다.

- 헤더: `마감 계좌`
- 현재 잔액 / 목표
- 납부 버튼
- 진행 게이지

제거한 중복 표시:

- 헤더의 `이자 10%` 문구
- 진행 게이지 아래 중복 `$현재 / $목표`
- `목표까지 $...` 설명
- `라운드 종료마다 잔액 +10%` 설명

이자 기능 자체는 그대로 작동합니다.

큰 금액에서는 잔액 / 목표 글씨를 단계적으로 축소하고 `nowrap`을 적용해 `$10,000` 이상에서 줄바꿈이 발생하지 않도록 보정합니다.

### 패턴 중앙 판정 배너 제거

기존 패턴 정산 중 중앙에 표시되던 다음 형태의 배너를 제거했습니다.

```text
판정 중
세로 3 · 코인 +$6
```

당첨 셀 / 라인 / 지급 숫자 연출은 유지합니다.

### 이번 라운드 수익 — 임시지갑

라운드 플레이 중 얻는 현금은 바로 왼쪽 지갑으로 이동하지 않습니다.

```text
리롤 +$12
→ 이번 라운드 수익 $12
→ 다음 리롤 +$8
→ 이번 라운드 수익 $20
→ 라운드 종료
→ 지갑 +$20
```

다음 현금 정산이 모두 포함됩니다.

- 일반 패턴
- Trigger 보너스
- Retrigger
- 저장금
- ERROR EVENT 현금

상점 / 납부는 원래 라운드 준비 시간에만 가능하므로 플레이 중 임시지갑에 묶여 있어도 기존 준비 경제 흐름과 충돌하지 않습니다.

### 라운드 종료 지갑 입금 연출

라운드 종료 시 임시지갑의 전체 금액이 한 번에 실제 지갑으로 이동합니다.

- `+$금액` 민트색 텍스트가 머신 쪽에서 지갑 방향으로 이동
- 지갑 금액 카운트업
- 지갑 근처에 큰 초록색 `+$금액` 플로팅
- 짧은 민트 글로우
- 화면 흔들림 없음

### 시장 연동 릴 고정 레이아웃 유지

v0.9.8의 고정 레이아웃을 유지하면서 임시지갑 공간 확보를 위해 머신 세로 공간만 소폭 확장했습니다.

- 결과 개수 / Trigger / Retrigger 개수에 따라 머신 전체 크기가 바뀌지 않음

## v0.9.6 — SHINY / 코인 상점 리롤 / 다크 모드

### SHINY

상점의 실제 보유 가능한 아이템은 기본 **4% 확률**로 SHINY가 될 수 있습니다.

SHINY Trait:

| Trait | 효과 |
| --- | --- |
| ✨ 증폭 | 모든 패턴 지급액 +5% |
| 🍀 행운 | 매 리롤 Luck +0.12 |
| 📈 복리 | 마감 계좌 이자 +1%p |
| 🔁 집착 | 마지막 당첨 패턴 8% 확률 재발동 |
| 🃏 변칙 | WILD 가중치 +0.5 |
| 🛒 상인 | Deadline 첫 상점 리롤 -30% |
| 🎟️ 배당 | Deadline 성공 시 티켓 +1 |

안전장치:

- SHINY 복리 추가 이자 최대 +5%p
- SHINY 상인 첫 리롤 할인 최대 50%
- 집착 재발동은 기존 Stage 9 재발동 상한 적용

### 상점 새로고침

아이템 구매는 티켓, 상점 새로고침은 지갑 `$`를 사용합니다.

```text
Deadline 목표의 15%
→ 같은 Deadline에서 새로고침마다 +5%p
→ 새 Deadline에서 다시 15%
```

기존 상점 아이템 변경:

- 새로고침 쿠폰: 비용 -20%
- 포인트 카드: 3회 새로고침마다 다음 1회 무료
- 과적재 선반: 공간 +3 / 새로고침 비용 +10%
