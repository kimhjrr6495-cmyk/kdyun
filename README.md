**Stage 4 — 마감 / 라운드 루프 / v0.4.0**

- 5×3 세로 릴
- v0.1.3에서 확정한 회전 속도 유지
- 가로 3/4/5, 세로, 대각선, V, 역 V, X 패턴 판정
- 겹쳐 성립하는 패턴 전부 합산
- 15칸 전체 동일 심볼 JACKPOT + 일반 패턴 동시 합산
- 심볼 가치 / 심볼 배율 / 패턴 기본값 / 패턴 배율 / 전체 배율 점수 구조
- 회전 지급액 숫자 카운트업
- 실제 회전 보상의 지갑 반영
- 마감 목표 진행 표시

- RISK: 3회전 + 티켓 3
- 회전 횟수 차감
- 마감당 최대 3라운드
- 라운드 종료 시 목표 달성 여부 판정
- 목표 달성 시 다음 Deadline 진행
- 3라운드 실패 시 GAME OVER

## Stage 4 라운드 규칙

한 Deadline은 최대 3라운드입니다.

라운드 시작마다 둘 중 하나를 선택합니다.

- `NORMAL`: 6회전 / 티켓 +1
- `RISK`: 3회전 / 티켓 +3

라운드의 회전을 모두 사용하면 목표를 확인합니다.

- 현재 보유액이 목표 이상이면 Deadline 성공
- 목표 미달 + 1~2라운드라면 다음 라운드 선택
- 목표 미달 + 3라운드 종료라면 GAME OVER

Stage 4에서는 목표를 달성해도 아직 목표액을 지갑에서 차감하지 않습니다. 실제 Deadline 정산, 금고 합산 방식, 이자, 조기상환은 Stage 5에서 구현합니다.

## 점수 계산

기본 공식:

`심볼 가치 × 심볼 배율 × 패턴 포함 칸 수 × 패턴 기본값 × 패턴 배율 × 전체 배율`

겹쳐 성립하는 패턴은 각각 계산합니다.

- V = 구성 대각선 2개 + V
- JACKPOT = 성립한 모든 일반 패턴 + JACKPOT 보너스
- 같은 가로 연속 구간에서는 가장 큰 가로 패턴만 계산

## 개발 테스트 버튼

`패턴 테스트`는 개발 중 검수용입니다.

- 패턴/점수 계산 미리보기
- 지갑 미반영
- 라운드 회전 횟수 미차감
- 티켓 변화 없음

## 아직 구현하지 않은 것

- 목표액 실제 정산/차감
- 금고 입출금
- 지갑 이자
- 조기상환
- 남은 라운드 티켓 보너스
- 상점
- 아이템 효과
- 실제 심볼 등장 확률 가중치
- 릴 정지 사운드
- 최종 JACKPOT/당첨/위험 연출
- 최종 엔딩 / Endless

- `data.js` — 심볼 / 패턴 / 점수 / Deadline / 라운드 데이터
- `game.js` — 릴 / 패턴 / 점수 / 지갑 / 라운드 / 마감 루프
- `effects.js` — 숫자 카운트업 / 민트 플래시
