# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯머신 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 5 — 지갑 / 금고 / 이자 / 마감 정산 / v0.5.0**

현재 구현된 것:

- 핀테크 / 트레이딩 앱 스타일 UI
- 5×3 세로 릴
- v0.1.3에서 확정한 회전 속도 유지
- 가로 3/4/5, 세로, 대각선, V, 역 V, X 패턴 판정
- 겹쳐 성립하는 패턴 전부 합산
- 15칸 전체 동일 심볼 JACKPOT + 일반 패턴 동시 합산
- 심볼 가치 / 심볼 배율 / 패턴 기본값 / 패턴 배율 / 전체 배율 점수 구조
- 회전 지급액 숫자 카운트업
- 실제 회전 보상의 지갑 반영
- NORMAL / RISK 라운드 선택
- NORMAL: 6회전 + 티켓 1
- RISK: 3회전 + 티켓 3
- 마감당 최대 3라운드
- 3라운드 실패 시 GAME OVER
- 지갑 ↔ 금고 자금 이동
- 지갑 라운드 종료 이자 5%
- 금고 이자 0%
- 지갑 + 금고 합산으로 Deadline 목표 판정
- Deadline 성공 시 목표액 실제 차감
- 목표 납부 우선순위: 지갑 → 금고
- 목표 달성 시 조기상환 가능
- 미사용 라운드당 티켓 +2 보너스
- 성공 후 남은 지갑/금고 잔액 다음 Deadline 이월

## Stage 5 경제 규칙

### 지갑

- 슬롯 보상은 지갑으로 들어옵니다.
- 라운드가 정상 종료될 때 지갑 잔액의 5%를 이자로 받습니다.
- 이자는 정수 화폐를 위해 반올림합니다.

### 금고

- `25% 입금`, `전액 입금`, `25% 출금`, `전액 출금`이 가능합니다.
- 금고 잔액에는 라운드 이자가 붙지 않습니다.
- 지갑과 금고 모두 Deadline 목표액 계산에는 포함됩니다.
- Error/위험 효과에 대한 금고의 실제 방어 역할은 해당 시스템이 추가되는 후속 단계에서 의미가 생깁니다.

### Deadline 정산

라운드 종료 후 순서:

1. 지갑에 5% 이자 적용
2. 지갑 + 금고 합계로 목표 달성 여부 확인
3. 목표 달성 시 목표액을 실제로 납부
4. 지갑에서 먼저 차감하고 부족한 금액은 금고에서 차감
5. 남은 잔액은 다음 Deadline으로 이월

### 조기상환

지갑 + 금고 합계가 목표 이상이면 라운드 도중에도 `조기 상환` 버튼이 활성화됩니다.

- 현재 라운드의 남은 회전을 즉시 포기하고 Deadline을 정산합니다.
- 아직 시작하지 않은 라운드마다 티켓 +2를 받습니다.
- 라운드 1 도중 조기상환: 남은 라운드 2개 → +4 티켓
- 라운드 2 도중 조기상환: 남은 라운드 1개 → +2 티켓
- 라운드 3: 추가 보너스 없음
- 라운드 종료 시 자동으로 목표를 달성한 경우에도 아직 시작하지 않은 라운드 보너스는 동일하게 지급됩니다.

## 점수 계산

기본 공식:

`심볼 가치 × 심볼 배율 × 패턴 포함 칸 수 × 패턴 기본값 × 패턴 배율 × 전체 배율`

겹쳐 성립하는 패턴은 각각 계산합니다.

- V = 구성 대각선 2개 + V
- JACKPOT = 성립한 모든 일반 패턴 + JACKPOT 보너스
- 같은 가로 연속 구간에서는 가장 큰 가로 패턴만 계산

## 개발 테스트 버튼

`패턴 테스트`는 개발 중 검수용입니다.

- 패턴/점수 계산 미리보기
- 지갑 미반영
- 라운드 회전 횟수 미차감
- 티켓 변화 없음

## 아직 구현하지 않은 것

- 상점
- 아이템 효과
- 실제 심볼 등장 확률 가중치
- Error / Wild / Luck 실제 시스템
- 릴 정지 사운드
- 최종 JACKPOT/당첨/위험 연출
- 최종 엔딩 / Endless
