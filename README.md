# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 8 — 트리거 / 연쇄 시스템 / v0.8.2**

현재 핵심 흐름:

1. 라운드 준비
2. 마감 납부 / 금고 / 상점 이용
3. `7회 리롤` 또는 `3회 리롤` 선택
4. 선택 즉시 라운드 시작
5. 릴 회전 완료 후 모든 릴의 위치/DOM을 최종 상태로 정규화
6. 화면이 최종 심볼 상태를 실제로 그린 뒤 패턴 판정
7. 검출된 패턴을 하나씩 순차 정산
8. 각 패턴 직후 Stage 8 트리거 큐 실행
9. 3라운드 종료 뒤 0라운드 최종 납부 또는 게임 오버 판정

## v0.8.2 릴 정지 / 패턴 판정 동기화

이전에는 마지막 릴의 `transitionend` 직후 곧바로 최종 DOM 교체와 패턴 판정 흐름이 이어졌습니다.
데이터는 이미 최종 심볼이더라도 브라우저 합성 프레임에서 마지막 릴의 transform 정리가 한 프레임 늦게 보일 수 있었습니다.

v0.8.2에서는 다음 순서로 강제합니다.

```text
각 릴 회전 종료
→ reel-track transition 제거
→ transform translate3d(0, 0, 0) 고정
→ 최종 3칸 DOM 재확정
→ 전체 릴 최종 상태 재검사
→ requestAnimationFrame 2회 대기
→ 패턴 판정 / 당첨 이펙트 시작
```

따라서 패턴 이펙트는 릴이 화면상 최종 위치에 완전히 정착한 이후에만 시작됩니다.

## v0.8.2 아이템 설명 용어

아이템 설명에서 `점수`라는 표현을 최대한 제거하고, 실제 게임 재화/지급 의미에 맞게 **기본 가치 / 지급액 / 추가 지급** 중심으로 정리했습니다.

예시:

- 체리 스티커 — `체리 기본 가치 +1`
- 다이아 커터 — `다이아 기본 가치 +3`
- 가로 배선 — `가로 패턴 지급액 증가`
- 잭팟 퓨즈 — `잭팟 지급액 증가`
- 시장 증폭기 — `모든 당첨 지급액 증가`
- 개장 알림 — `첫 리롤 지급액 증가`
- 에코 칩 — `패턴 당첨 시 추가 지급`
- 잭팟 축전기 — `잭팟 정산 시 추가 지급`

숫자가 없으면 효과를 이해하기 어려운 `+1`, `-1T`, `6종 이상` 같은 핵심 수치는 계속 표시합니다.

## v0.8.2 개발 테스트 버튼

지갑 영역에 개발 테스트 버튼 2개가 있습니다.

- `TEST +$100` — 지갑에 $100 추가
- `TEST +5T` — 티켓 5개 추가

두 버튼 모두 개발 중 마감/상점/아이템 흐름 테스트용이며 최종 빌드 전에 제거할 예정입니다.

## v0.8.1 리롤 선택 티켓 보상 표시

`티켓 펀치`처럼 라운드 시작 보상 티켓을 증가시키는 아이템을 보유하면 리롤 선택 버튼도 실제 획득 예정량을 표시합니다.

기본:

```text
7회 리롤 — 티켓 +1
3회 리롤 — 티켓 +3
```

티켓 펀치 1개:

```text
7회 리롤 — 티켓 +2
3회 리롤 — 티켓 +4
```

아이템 구매/판매 후 즉시 다시 계산합니다.

## Stage 8 트리거 큐

패턴 하나가 정산되면 `PATTERN_SETTLED` 이벤트가 생성됩니다.
보유한 트리거 아이템이 조건을 만족하면 추가 지급을 만들고, 그 지급은 다시 `BONUS_GRANTED` 이벤트를 만들 수 있습니다.

무한 연쇄 방지:

- 최대 연쇄 깊이: 4
- 한 원본 패턴당 최대 트리거 발동: 12회
- 같은 아이템 인스턴스 반복 발동 금지

### Stage 8 연쇄 아이템 6개

| 아이템 | 가격 | 화면 설명 |
| --- | ---: | --- |
| 에코 칩 | 3T | 패턴 당첨 시 추가 지급 |
| 가로 릴레이 | 3T | 가로 패턴 당첨 시 추가 지급 |
| 다이아 에코 | 4T | 다이아 패턴 당첨 시 추가 지급 |
| 잭팟 축전기 | 5T | 잭팟 정산 시 추가 지급 |
| 증폭 코일 | 4T | 트리거 보너스 추가 지급 |
| 연쇄 계전기 | 4T | 연쇄 발동 시 추가 지급 |

기존 Stage 7 아이템 20개를 포함해 현재 상점 풀은 총 26개입니다.

## 패턴 정산 순서

같은 종류의 패턴도 하나씩 처리합니다.

1. 가로 — 위쪽 줄부터 아래쪽 줄
2. 세로 — 왼쪽 열부터 오른쪽 열
3. 대각선
4. V
5. 역 V
6. X
7. 잭팟

각 패턴의 지급과 해당 패턴의 트리거 연쇄가 모두 끝난 뒤 다음 패턴으로 넘어갑니다.

## 당첨 연출 / 잭팟

일반 패턴:

- 현재 패턴 칸 포커스
- 나머지 칸 일시적으로 어둡게 처리
- 패턴 라인 스캔
- 노드 / 테두리 펄스 / 스파크
- 중앙 지급액 배너
- 지급액 / 지갑 순차 누적

잭팟은 화면 중앙 방사형 flare를 사용하지 않습니다.
`reels-shell` 이중 테두리, 5개 릴 테두리 강조, 심볼 색 글로우, 상승 차임 + 마지막 코드 방식입니다.

## 실시간 심볼 가치 / 패턴 배수

오른쪽 심볼 표:

`등장확률 | 심볼 | 현재 가치 | 변화식`

현재 심볼 추첨은 7종 균등 랜덤이므로 실제 등장확률은 각 약 `14.3%`입니다.

계산 규칙:

`현재 심볼 가치 = 기본 심볼 가치 × 곱보정 + 합보정`

`현재 패턴 배수 = 기본 패턴 값 × 곱보정 + 합보정`
