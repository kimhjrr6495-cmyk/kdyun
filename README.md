# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯머신 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 3 — 점수 시스템 / v0.3.0**

현재 구현된 것:

- 핀테크 / 트레이딩 앱 스타일 UI
- 5×3 세로 릴
- v0.1.3에서 확정한 회전 속도 유지
- 가로 3/4/5, 세로, 대각선, V, 역 V, X 패턴 판정
- 15칸 전체 동일 심볼 JACKPOT 판정
- 패턴 당첨 칸 강조
- 7종 심볼 기본 가치
- `기본 가치 × 칸 수 × 패턴 배율` 점수 계산
- 소수 점수 발생 시 패턴별 반올림
- 회전 지급액 숫자 카운트업
- 실제 회전 보상의 지갑 반영
- 지갑/목표 진행 표시
- 최소 민트색 당첨 플래시
- 패턴별 계산 내역 표시
- 9종 패턴 테스트 보드

## 심볼 기본 가치

- 체리: 2
- 코인: 2
- 벨: 3
- 스타: 4
- 다이아: 6
- 크라운: 8
- 세븐: 12

현재 Stage 3에서는 심볼 등장 확률 가중치를 아직 연결하지 않았습니다.

## 패턴 배율

- 가로 3: ×1
- 가로 4: ×2
- 가로 5: ×4
- 세로 3: ×1.5
- 대각선: ×2
- V: ×6
- 역 V: ×6
- X: ×8
- JACKPOT: ×12 (임시값, 추후 밸런스 조정)

## 점수 계산

기본 공식:

`심볼 기본 가치 × 패턴 포함 칸 수 × 패턴 배율`

예시:

`벨 3 × 세로 3칸 × 1.5 = 13.5 → $14`

각 패턴 결과를 반올림한 뒤 한 회전의 모든 패턴 점수를 합산합니다.

## 테스트 버튼 규칙

`패턴 테스트` 버튼은 개발 중 검수용입니다.

- 패턴/점수 계산은 수행
- 지급액 미리보기 표시
- 지갑에는 반영하지 않음

실제 `회전` 버튼/Space 키로 나온 결과만 지갑에 반영됩니다.

## 아직 구현하지 않은 것

- 실제 라운드 회전 횟수
- NORMAL / RISK 선택
- Deadline 성공/실패
- 금고 입출금
- 이자
- 상점
- 아이템 효과
- 실제 등장 확률 가중치
- 릴 정지 사운드
- 최종 당첨/JACKPOT 연출

## 파일 구조

- `index.html` — 메인 화면 구조
- `style.css` — UI / 최소 당첨 피드백
- `data.js` — 심볼 가치 / 패턴 배율 / 릴 파라미터
- `game.js` — 릴 / 패턴 / 점수 / 지갑 로직
- `effects.js` — 숫자 카운트업 / 민트 플래시
