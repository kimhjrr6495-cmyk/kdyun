# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯머신 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 0 — 프로젝트 뼈대 / 메인 UI**

현재 구현된 것은 정적인 화면 구성뿐입니다.

- 핀테크 / 트레이딩 앱 스타일 UI
- 왼쪽 마감·지갑·금고 정보 패널
- 중앙 5×3 슬롯 영역 목업
- 상단 마감·라운드·회전·티켓 상태 UI
- 오른쪽 마우스 오버형 아이템 패널 미리보기
- 반응형 기본 레이아웃
- GitHub Pages에서 정적 파일로 실행 가능한 상대경로 구조

## 아직 구현하지 않은 것

- 슬롯 회전
- 랜덤 심볼 생성
- 패턴 판정
- 점수 계산
- 마감 / 라운드 실제 로직
- 상점
- 아이템 효과
- 사운드
- 당첨 / 위험 이펙트

이 항목들은 단계별로 구현합니다.

## 파일 구조

- `index.html` — 메인 화면 구조
- `style.css` — 전체 UI 스타일
- `data.js` — 게임 데이터 정의용
- `game.js` — 게임 로직용
- `effects.js` — 시각 / 사운드 이펙트용
