# DEADLINE

CloverPit에서 영감을 받은 2D 5×3 슬롯 로그라이트 프로젝트입니다.

## 현재 개발 단계

**Stage 8 — 트리거 / 연쇄 시스템 / v0.8.0**

현재 핵심 흐름:

1. 라운드 준비
2. 마감 납부 / 금고 / 상점 이용
3. `7회 리롤(+1T)` 또는 `3회 리롤(+3T)` 선택
4. 선택 즉시 라운드 시작
5. 검출된 패턴을 하나씩 순차 정산
6. 각 패턴 정산 직후 Stage 8 트리거 큐 실행
7. 아이템 발동 → 추가 지급 → 다른 아이템 반응 → 다음 패턴
8. 3라운드 종료 뒤 0라운드 최종 납부 또는 게임 오버 판정

## Stage 8 트리거 큐

패턴 하나가 정산되면 `PATTERN_SETTLED` 이벤트가 생성됩니다.
보유한 트리거 아이템이 조건을 만족하면 순서대로 발동하며 추가 지급을 만들고, 그 지급은 다시 `BONUS_GRANTED` 이벤트를 생성할 수 있습니다.

예시:

```text
다이아 가로 5 정산
→ 에코 칩 발동
→ 가로 릴레이 발동
→ 다이아 에코 발동
→ 증폭 코일이 트리거 보너스에 반응
→ 연쇄 계전기 발동
→ 다음 패턴 정산
```

각 원본 패턴마다 같은 아이템 인스턴스는 한 번만 발동합니다.
중복 보유 아이템은 서로 다른 인스턴스이므로 각각 한 번씩 발동할 수 있습니다.

무한 연쇄 방지:

- 최대 연쇄 깊이: 4
- 한 원본 패턴당 최대 트리거 발동: 12회
- 자기 자신을 다시 계속 부르는 반복 발동 금지

## Stage 8 신규 연쇄 아이템 6개

| 아이템 | 가격 | 효과 |
| --- | ---: | --- |
| 에코 칩 | 3T | 모든 패턴 당첨 시 원본 점수의 15% 추가 지급 |
| 가로 릴레이 | 3T | 가로 3/4/5 당첨 시 원본 점수의 25% 추가 지급 |
| 다이아 에코 | 4T | 다이아 패턴 당첨 시 원본 점수의 35% 추가 지급 |
| 잭팟 축전기 | 5T | 잭팟 정산 시 원본 점수의 75% 추가 지급 |
| 증폭 코일 | 4T | 다른 트리거가 만든 보너스의 50%를 다시 추가 지급 |
| 연쇄 계전기 | 4T | 같은 패턴에서 트리거가 2회 이상 이어지면 원본 점수의 25% 추가 지급 |

기존 Stage 7 아이템 20개는 그대로 유지되며, 상점은 총 26개 풀에서 4개를 제안합니다.

## 트리거 피드백

트리거가 발동하면 패턴 정산 UI 사이에 작은 로그가 나타납니다.

- 아이템 이름
- 발동 순서
- 연쇄 깊이
- 추가 지급액
- 현재 `CHAIN xN`
- 해당 패턴의 누적 트리거 보너스

한 회전이 끝나면 `트리거 총 발동 횟수 / 총 연쇄 보너스 / 최대 CHAIN` 요약을 표시합니다.

오른쪽 임시 스탯에도 다음 항목을 추가했습니다.

- 트리거 발동
- 연쇄 보너스
- 최대 연쇄

**오른쪽 스탯 패널은 여전히 임시 개발 UI이며 최종 UI 단계에서 제거 예정입니다.**

## 패턴 정산 순서

같은 종류라도 패턴 하나씩 처리합니다.

1. 가로 — 위쪽 줄부터 아래쪽 줄
2. 세로 — 왼쪽 열부터 오른쪽 열
3. 대각선
4. V
5. 역 V
6. X
7. 잭팟

각 패턴의 기본 지급이 끝난 뒤 그 패턴에 대한 트리거 큐가 전부 끝나야 다음 패턴으로 이동합니다.

## 당첨 연출

현재 패턴 정산 시:

- 해당 패턴 칸만 포커스
- 나머지 칸 일시적으로 어둡게 처리
- 패턴 모양 라인 스캔
- 노드 / 테두리 펄스 / 짧은 스파크
- 중앙 패턴 이름 / 지급액 배너
- 지급액과 지갑 숫자 순차 누적

Stage 8 트리거 발동 때는 릴 외곽이 짧게 반응하고, 작은 연쇄 로그와 벨 계열 피드백을 추가합니다.

## 잭팟

화면 중앙의 방사형 flare는 사용하지 않습니다.

잭팟 피니시는:

- `reels-shell` 이중 테두리
- 5개 릴 테두리 동시 강조
- 심볼 색 기반 짧은 글로우
- 상승 차임 + 마지막 코드

방식으로 처리합니다.

## 실시간 심볼 가치 / 패턴 배수

오른쪽 심볼 표:

`등장확률 | 심볼 | 현재 가치 | 변화식`

예시:

```text
14.3%  다이아  $9 (+3)
14.3%  세븐    $24 (×2)
14.3%  체리    $6 (×2 +2)
```

현재 심볼 추첨은 아직 7종 균등 랜덤이므로 각 심볼 실제 등장확률은 약 `14.3%`입니다.

계산 규칙:

`현재 심볼 가치 = 기본 심볼 가치 × 곱보정 + 합보정`

`현재 패턴 배수 = 기본 패턴 값 × 곱보정 + 합보정`

강화된 값은 상승 비율에 따라 그린 → 바이올렛 → 골드 → 마젠타 계열로 점점 더 희귀하게 표시됩니다.

## 라운드 준비 / 상점

- 라운드 준비 중에만 납부 / 금고 / 상점 사용 가능
- `7회` 또는 `3회` 클릭 즉시 라운드 시작
- 별도 시작 버튼 없음
- 선택 클릭 자체는 실제 리롤을 소비하지 않음
- 상점 / 정산 / 마감 성공 / 0라운드 등 차단 상태에서는 7회/3회 선택 UI 숨김
- 상점 최대 보유 아이템 6개
